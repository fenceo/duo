# 知识文档与统一目录

从 v0.34.60 起，任务过程、平台共识、系统知识和项目知识按用途分层。设置与日常操作请先阅读[分层知识与任务记忆](knowledge-layers.md)。下文的 `Duo/tasks/`、候选结论及主题索引继续作为兼容资料与可选镜像保留；任务过程的新主目录为实际工作区中的 `.duo/`，不会自动删除旧文档。

知识库直接显示 Markdown 列表。“任务资料”以一任务一文档展示；通用知识和主题索引保留独立入口。关键词、任务和自动标签可缩小范围；全部文档包含旧摘录及加入目录的普通 Markdown。

## 文件组织

未配置过目录时，在当前运行数据目录下自动建立 `knowledge/Duo/`。在顶部“知识库 → 积累设置”中配置一个根目录，支持普通文件夹和 Obsidian Vault；留空使用默认位置，自选文件夹需先存在。实际文档位置会在同一页面显示。阅读时切换到“知识库 → 浏览资料 → 任务资料”，或直接在所选目录内打开 `Duo/README.md`。知识浏览和积累设置共用一个知识库窗口，不再单设顶部“知识积累”入口。

若要随对话更新任务文档，在“积累设置”中开启“Markdown 同步与索引”和“同步自动整理的任务资料”，保存路径与同步设置；再开启自动记录、自动整理并保存。两组设置分别保存，切换知识库页面或关闭知识库弹窗不会覆盖当前网页中的未保存修改；保存失败时可以保留草稿重试。

```text
<选定根目录>/Duo/
  README.md                       # 全部任务与主题的目录
  tasks/<任务名>-<短ID>.md         # 日常阅读的任务记录，一任务一文档
  tasks/<稳定任务ID>/
    summary.md                    # 旧摘要链接入口；迁移后指向任务记录
    context.md                    # 前提、共识、未决问题及来源
    conversations.md              # 所有已结束轮次的目录
    conversations/<轮次ID>.md     # 要求、中途补充、回复及错误
    notes/<笔记ID>.md             # 手工笔记和旧整理结果
  knowledge/<轮次ID>-<序号>.md    # 可复用的问题、结论、依据、适用条件
  topics/<标签稳定ID>.md          # 自动主题索引
  自己的文档.md                    # 支持普通 UTF-8 Markdown
```

任务记录的文件名使用任务名和 8 位短 ID，同名任务各有自己的文档；短 ID 碰撞时扩展为完整 ID。首次导出后固定文件名，任务改名只更新正文和标题，保留 Obsidian 反向链接。原始逐轮对话仍使用稳定 ID 目录。文档采用相对链接，工作区路径能确定时转换成 `<workspace>`，其他本机路径使用占位；原始运行数据库不改写。常见凭据脱敏，正常网页来源链接保留。Duo 与 AHA 没有运行依赖或数据目录耦合。

任务记录按“任务目标、当前进展、当前计划、继续任务的前提、进展记录、决策与证据、验证与可复用结论、未决问题、已有笔记”组织。目标摘自最早一轮用户要求并注明来源；当前计划只展示最近一轮留下的待办与待确认事项，没有记录时明确显示暂无，不把历史结果推定成新计划。进展记录按时间展示最近 60 轮整理，前提历史页保留最近 30 次，早期资料仍可通过逐轮来源查阅。

第一层随对话保存，整理成功后补充记录；没有摘要的旧任务显示原记录入口。第二层要求来源回复中有可找到的依据，Duo 不独立认证结论。第三层按标签汇集通用知识，不自动推导新理论或消除分歧。列表、文档生成和文件同步均不额外调用模型。

点击标题阅读全文，长文档分段展示，可继续阅读或下载 Markdown。相对来源链接可直接打开任务摘要、对话或笔记。完整阅读和引用预算相互独立，其他任务资料选择后先加入当前草稿。自动消费说明见[对话自动积累](automatic-knowledge.md)。

## 同步与迁移

- 新配置默认启用文件保存。旧的关闭设置和导出范围保留；原来关闭自动资料导出的，需要在“知识库 → 积累设置”中打开。关闭不删除旧文件。
- 后台每分钟同步，“刷新文件”可立即读取外部编辑。后台复用未变化文件的解析结果，空闲同步不反复改写索引。
- 旧平铺文档在已跟踪文件未变化、新路径不存在时迁入任务目录。有编辑先按原冲突规则处理；不覆盖新路径，被外部删除的已跟踪文件不自动恢复。
- 旧 `tasks/<任务ID>/summary.md` 未被外部修改时迁到可读任务文件，原位置保留相对链接入口；旧引用仍可打开。若旧摘要有外部正文编辑，则保留旧文件为实际任务入口，目录及来源链接继续指向它，并按同步规则提示冲突，避免留下断链或覆盖批注。
- 手工笔记支持 Duo 与 Markdown 双向更新。自动摘要/目录若同时有外部修改和新生成内容，保留外部文件并提示冲突；不能静默覆盖。原始执行数据库不受外部 Markdown 编辑影响。
- 更换根目录在新位置同步当前范围，旧文件保留；独立文档需要自行复制。Duo 只管理选定根目录下的 `Duo/`。
- 可通过 Git/Obsidian 同步整个 `Duo/`，另一电脑不需要原任务数据库即可索引和引用。Duo 不自动提交、推送或保存 Git 凭据。
- 新版工作区导出/导入包含结构化摘要，导入时重建任务和轮次关联；Markdown 仍独立于运行数据库。

保留 `duo_id`、`duo_kind`、`duo_task`、`duo_run` 等关联字段。自动标签放在 `tags`，兼容外部编辑器的列表和单行标签；未知属性保留。运行环境、原生会话、凭据、工具日志及附件不导出到知识文档。

只索引 `Duo/` 内非隐藏的普通 Markdown，跳过符号链接和目录联接。单文件 2 MiB，总计 10000 文件 / 128 MiB；超限、无效 YAML、Git 冲突会报告，不假装完整导入。旧数据库与知识不因升级删除。
