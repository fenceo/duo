# 对话自动积累

v0.34.60 新增工作区交接与显式整理的三类正式知识。完整操作见[分层知识与任务记忆](knowledge-layers.md)；下文说明原始任务资料及候选结论。自动记录无需逐条分类，但正式知识的已验证状态需要用户确认。

以任务文档为主，不必逐条分类或维护验证状态。任务菜单“任务记录”直接打开工作区的 `任务记录.md`，可在 Duo 阅读、编辑并保存回同一文件。总菜单“知识库”管理平台共识、系统知识和项目知识；目录和自动记录开关在同一窗口的“积累设置”页配置。旧 Obsidian 任务镜像、候选和主题索引仍可在历史资料中读取。

## 记录与整理

普通对话继续保存在运行数据库中，逐轮文档包括要求、中途补充、回复及错误。成功轮次保留原有摘录，并在同一轮模型请求里附带可选整理约定：摘要、前提、共识、未决问题、标签及有依据的通用知识。Duo 不为整理启动额外模型轮次，不要求模型为此调用工具。

合法附加结构不显示为聊天正文；没有合法整理结果时保留原回复，不伪造摘要。用户要求严格输出格式时优先遵循用户要求，可以省略整理。通用知识的依据必须逐字出现在该轮正常回复中；这只证明出处，不代表 Duo 独立完成了实验或核实事实。未决事项不冒充结论，主题索引不擅自融合分歧。

标签优先来自模型，辅以本地关键词规则，去重并限制数量。“知识库 → 积累设置”可分别关闭自动记录、随对话整理和新会话补回。路径与同步设置、自动记录与整理设置分别保存；切换知识库页面或关闭知识库弹窗不覆盖当前网页中的未保存修改。关闭自动记录或整理不删除旧资料，也不能从已有原生会话中撤回先前引用。读取设置失败时不默认打开。

原有 `knowledge_entries` 摘录保持兼容，结构化增量保存在 `task_memories`。重复完成回调不覆盖摘要；失败轮次不新增结构化知识。旧验证字段保留以兼容历史，日常界面不再要求维护。

工作区主文档分为任务目标、当前计划、备注和进展记录。初建目标节选最早用户要求，顶部计划留待用户维护；每轮结束后按来源追加进展、决策、依据和未决事项，不自动改写人工正文。没有结构化整理时标明原始对话摘录，失败状态及错误照实保留。每项进展可回到逐轮来源，阅读和回填仅使用已保存记录，不再次请求模型。旧 Obsidian 任务镜像继续保留原来的目标、计划、进展等汇总格式，不作为新的工作区主文档。

## 消费路径

连续聊天沿用原生会话。开启自动补回后，新会话读取本任务主 Markdown 的有限摘录（长文保留开头与结尾），也补回本任务最近三份结构化进展、前提、共识和未决问题，每份最多 1200 字；没有结构化资料时回退到原有摘录。已有原生会话不重复重放主文档，显式选择的简要恢复范围保持不变。资料带来源，不授予执行权限。

其他任务和独立文档通过知识库选择引用。文档可完整阅读，写入输入框的引用最多 6000 字符，带来源、版本指纹与截断提示。选择后内容变化会拒绝过期引用；切换任务不重定向迟到的请求。打开列表、全文、标签检索和文件同步不会调用模型。

同轮整理会增加本次请求的提示与输出 token，自动补回计入下一轮输入。测试仅使用合成引擎验证协议，没有调用真实模型验证整理质量。旧对话不自动消耗模型补做摘要，可以继续查阅或主动整理。

文件结构与迁移规则见[知识文档目录](knowledge-vault.md)。
