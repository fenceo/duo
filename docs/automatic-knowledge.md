# 对话自动积累

从 0.22.0 开始，正常聊天即可积累，不需要每轮点击保存或执行复盘。默认开启两个本机设置，可在 **设置 → 知识库 → 对话自动积累** 分别关闭。

## 自动记录

一轮普通对话成功完成后，Duo 在保存执行结果的同一事务中，把本轮要求（最多 400 字）与最终回复写入 `knowledge_entries`，关联原任务与 `run_id`，来源为 `auto`，状态为 `observed`（待验证）。对话底部显示“已自动记录”，任务知识中显示“对话自动记录”，本机知识库立即可检索。限制要求长度可为自动恢复中的回复内容保留空间；完整要求仍在原始执行记录中。

它保存本轮要求与已有回复，不另外请求模型做摘要，不扫描项目文件，也不读取工具日志或附件。相同任务中完全相同且未截断的问题与回复不重复添加；语义相似或互相矛盾的回复不会被自动合并。失败、中断、空回复和专用整理知识草稿不自动记录。原始 runs/events 仍保留，自动知识会先去除常见凭据，超出 200000 字节时截断并标注。

执行成功不等于结论正确，所以不会自动标为已验证。需要时可以编辑、验证、设为过时或删除；无需先做这些操作才能继续聊天。重复的完成回调不会覆盖人工修改或恢复删除的条目。关闭自动记录后，后续完成的轮次不新增条目，已有内容保留。升级前的旧记录不自动回填。

## 自动消费

连续聊天仍使用原生会话。任务开启新的原生会话时，Duo 自动附带当前任务的最多 3 条知识，优先已验证，再按更新时间选择，每条正文最多 1200 字。引用包含知识 ID、来源轮次、验证状态与截断标记，并明确属于历史资料。恢复记录可在该轮“执行记录”查看。

自动恢复不会读取其他任务或独立 Vault 文档，排除过时知识，也不会恢复完整聊天或原生 session。正常续聊不重复附带资料。自动恢复没有额外模型请求，但引用文字计入该轮输入 token。

若要完全空白的 AI 上下文，先在“设置 → 知识库”关闭“新建会话时自动补回当前任务知识”，再新建会话。关闭不会从仍在使用的原生会话里撤回已经发送的资料。跨任务消费继续使用“引用历史 / 知识”，检查后发送。

## Markdown / Obsidian

自动条目默认只进入本机数据库。需要 Markdown 持续积累时，在 **设置 → 知识库 → 知识文件目录与同步** 配置一次 Vault 路径并勾选“同步自动积累的知识”。之后复用每分钟同步流程，路径为 `<Vault>/Duo/knowledge/<ID>.md`，不需要逐轮操作。

这个选项与“同时保存全部任务的已结束对话记录”独立。人工保存的知识继续按原设置同步。关闭导出不删除已有文件；Git 推送仍由用户配置的 Git/Obsidian 工具完成。凭据脱敏只能覆盖常见格式，不能保证任意回复均无私人内容。

## 实现与验证

设置持久化在 SQLite `settings.automatic_knowledge`，`capture`、`recall` 默认均为 `true`；设置 API 为 `GET/PUT /api/library/automatic`，沿用登录与 CSRF 校验。Vault 设置新增 `include_automatic`，默认 `false`，无需迁移已有任务数据。

自动记录不创建额外队列任务，不消耗额外模型轮次。记录失败不丢弃原始回复，会留下可见执行记录，允许手动补存。本地测试使用合成数据与模拟引擎，覆盖自动写入、设置开关、去重、人工修改、删除、失败隔离、上下文范围与长度、会话重置和 Vault 导出边界。
