# 环境账号与任务

v0.31.0 起，账号按「执行环境 + AI 引擎」设置。例如 Ubuntu WSL 的 Codex 与该环境的 Claude 有各自的当前账号；另一个 WSL 发行版、Windows、SSH 主机也分别管理。

- 在账号卡片点击「切换环境账号」。新任务默认跟随；已有的跟随任务在下一轮开始执行时使用新账号，包括尚未开始执行的排队消息。已经启动 CLI 的一轮保留原账号。
- 在「切换 AI → 账号 / API 配置」选择「跟随环境账号」，可让原来单独指定账号的任务恢复跟随。卡片的「仅此任务使用」打开切换预览，确认后固定该任务账号，不改变环境账号。
- 切换账号会建立新原生会话，通过接续摘要和完整任务历史继续。自动切换时包含上一轮刚完成的回复，记录和知识仍留在同一个任务内。相同账号的后续轮次继续原生会话，不重复重建。
- 模型列表和模型测试确认读取下一轮要使用的账号。排队消息仍保留提交时的模型、权限和账号模式；环境模式的账号则以开始执行时为准。

「切换环境账号」为 Duo 在该环境启动的任务选择独立配置目录，不覆盖终端里的原生登录。「同步到环境」会写入所选 Windows / WSL / SSH 的原生登录和服务配置，并将该环境的 Duo 当前账号恢复为原生登录。两者均可用于跟随环境的任务。原生同步要求目标环境的同一引擎没有运行或排队任务；外部 CLI 需自行关闭后重新打开。原文件保留备份。

升级时，没有手动「切换 AI」记录的旧绑定转为跟随环境；存在手动切换记录的旧绑定保留为单独指定，以免丢失原本的任务选择。旧版本缺少账号绑定且已有原生会话的任务，仍需在「切换 AI」中确认归属或新建接续会话。迁移不改写原生会话、不启动模型。

独立目录引用被删除后，单独指定的任务仍保留原目录；跟随任务改用环境当前配置。外部程序直接修改同一账号目录的行为不在 Duo 的账号隔离范围内；通过 Duo 原生同步的登录变更有版本记录，下一轮会建立新会话，避免误用旧账号的会话。

合成回归覆盖：多轮排队期间切换、运行账号不漂移、上一轮历史接续、后续会话复用、固定账号、恢复跟随、预览过期拒绝、迁移幂等、环境/引擎隔离、同目录原生登录变更、事务失败回滚和忙碌环境同步拦截。未调用真实模型。
