# 环境账号管理

v0.31.1 起，账号管理只负责账号列表、添加/导入、身份与额度刷新，以及目标环境的原生账号切换。

1. 在 Codex / Claude 账号卡片选择「切换到环境」。
2. 勾选一个或多个 Windows、WSL、SSH 环境，确认切换。
3. Duo 在目标原生目录备份并更新登录文件和 API 服务配置，逐个环境报告结果。卡片显示上次成功切换到的环境。

账号不绑定对话或任务。切换不读取或修改任务、会话 ID、模型、草稿或排队消息，不自动创建新会话，不复制或回放历史。任务按原方式调用目标环境的 CLI，由 CLI 读取该环境的原生账号。已启动进程是否立即读取新的登录由原生工具决定，必要时重新打开；Duo 不因账号切换中断或重启任务。

「切换 AI」只选择引擎、模型、权限和执行位置。跨引擎或执行位置的历史接续独立保留，单纯切换账号不触发接续。

升级保留旧任务数据和账号字段作为历史记录，不再使用旧字段覆盖 Codex/Claude 原生登录，不迁移或重建会话。旧隔离目录中的原生会话能否在当前目录恢复由 CLI 决定；恢复失败应呈现原生错误，不自动重建。真实账号及旧隔离目录会话恢复尚未实测。

旧版本「设为默认 / 切换环境账号」仅改变 Duo 配置引用，不能证明原生登录已经切换，因此不显示为已成功应用；需要在新入口明确执行一次切换。移除账号只移除 Duo 管理引用，不删除源文件或退出目标环境的登录。

Codex 使用目标环境的原生 CODEX_HOME 或默认 .codex，Claude 使用原生 CLAUDE_CONFIG_DIR 或默认 .claude。账号库存储目录用于保存、读取和切换凭据，不再作为任务专属运行目录。Harness 的环境配置目录仍由环境设置管理。

自动化回归仅使用临时账号文件和模拟执行器，验证运行/排队任务不被账号切换修改、后续 CLI 调用读取新的原生登录、会话 ID 不变、无接续档案，以及环境与引擎隔离。
