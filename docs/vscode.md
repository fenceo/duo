# 在 VS Code 中查看任务项目

在左侧任务的三个点菜单选择“在 VS Code 中打开”，或在“文件”面板点击“在 VS Code 打开项目”。预览连接环境和目录，勾选目标设备/连接匹配后点击“打开 VS Code”。窗口打开在当前访问网页的设备上，文件保留在任务所在执行环境；Duo 服务不在后台启动编辑器进程，不创建 AI 会话。

- Windows：打开本机盘符路径。请在项目所在电脑访问 Duo；从手机或另一台电脑访问时，同名路径不代表同一个项目。UNC 网络共享路径暂不支持。
- WSL：本机需安装 VS Code 和 WSL 扩展，连接任务的同名发行版。VS Code 使用发行版默认用户，任务指定用户时必须确认二者一致；Duo 不改变 WSL 默认用户。
- SSH：本机需安装 Remote - SSH 扩展，在连接预览中填写本机 SSH 配置的 Host 别名。可复制预览生成的 HostName / User / Port 配置，添加到本机 SSH 配置；已有别名必须匹配任务的主机、用户和端口。私钥、代理、跳板及目标机器依赖自行配置，Duo 不复制凭据或写入 SSH 配置。

文件预览工具栏支持输入行号再打开文件。对话中常见代码文件的行内引用（如 `src/app.ts:42`）、Markdown 文件链接和任务目录内绝对路径，可点击在编辑器中定位；代码块和工作目录外的引用保持普通文字。文件打开前复用现有文件读取接口检查路径和符号链接边界。Git 差异中的行号可能属于旧文件，请指定当前文件的行号；删除文件无法再作为现有文件打开。

浏览器可能要求允许打开外部应用；如果没有响应，可以复制连接预览中的 CLI 命令到当前设备终端运行。网页只知道请求已发出，不能确认 VS Code 是否打开成功。远程扩展按自身流程安装后端、确认主机与工作区信任，不需要远端完整桌面或桌面投屏。

编辑器与 AI 会读写同一份文件。手动编辑请保存后再让 AI 继续；AI 运行时避免同时编辑同一个文件，尤其注意尚未保存的编辑器缓冲区。本版没有 VS Code 侧栏插件、会话同步或自动冲突合并。
