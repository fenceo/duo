# v0.34.26

- 模型下拉菜单新增“应答延时测试”：只测试当前明确选择的一个模型，默认等待 180 秒，可选 60～600 秒，适用于超过一分钟才有回复的情况。
- 分别显示首次可见回复及完整调用耗时，等待中可停止；连接提示不计作模型回复，失败或超时保留已观测的首次时间。计时包含 CLI 启动和原生重试，不冒称 OpenAI 网络首包时间。
- 保留现有列表快速测试、账号/API 确认与任务绑定校验。延时测试使用独立原生会话；不改变当前任务和普通任务超时。MiMo 非流式 API 测试暂不测首次回复。
- 已托管升级 CLI 的旧任务，模型目录和模型测试使用同一条可信升级映射；手工路径或执行目标改变时仍拒绝跟随。

操作和测量边界见 [模型应答延时测试](../model-latency-tests.md)。

延时回归使用合成 CLI，分别验证 65 秒延迟初始化，以及连接确认后 65 秒才输出文本；不调用真实模型或修改原任务。网页回归覆盖单模型范围、等待/停止、首段与总耗时、陈旧结果隔离和可信升级路径。
