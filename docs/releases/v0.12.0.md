# v0.12.0

简作首次公开发布，提供 Windows x64 便携包和源码。

- Windows、WSL、SSH 工作区，Codex CLI 和 Claude Code 原生任务会话。
- 飞书任务入口、任务知识、彩色便签和统一搜索。
- 工作模式、快捷指令、附件、任务归档与回收站。
- 串口和继电器调试，按任务授权 AI 使用硬件。
- 设置新增“版本更新”：检查 GitHub 正式版本、更新说明和下载入口。

## 下载

下载 `Jianzuo-portable-windows-x64.zip` 后完整解压，双击 `简作.exe`。`Jianzuo-portable-windows-x64.zip.sha256` 用于校验下载完整性。

已有用户：先退出程序并备份 data，替换程序文件时保留 data。新版本不会迁移或重置 AI 工具账号。旧执行记录没有保存用量时显示“未提供”。

版本检查只读取公开发布信息，不上传本机任务或账号，不自动安装更新。
