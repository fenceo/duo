# Duo v0.21.1

修复长 Codex 会话继续提问时，在模型开始回复前报 `bufio.Scanner: token too long` 的问题。旧版恢复原生会话会一次性接收完整历史，超过 4 MiB 的返回消息会让本轮失败。

- 恢复同一个 Codex 线程时使用 `excludeTurns`，只省略返回给 Duo 的历史明细。模型仍加载原生会话上下文，不清空、不重建线程，不删除任务记录。
- 支持超过原 4 MiB 上限的历史回复和工具结果；单条消息保留 64 MiB 保护上限，并限制消息排队量。超限时明确说明原因，不展示消息内容或冒充成功。
- 修复可选 MCP 服务初始化失败时，字符串形式的错误被误判为无效事件、连带终止任务的问题。保留 MCP 错误提示，必需服务的原生启动失败仍会阻止执行。
- 离线回归覆盖长历史恢复、大工具输出、超限退出、可选 MCP 失败、原生线程身份及取消/审批行为。测试不请求真实模型。

已失败的那轮不会自动重发。升级后在原任务继续发送即可，无需删除会话、修改模型或重新填写 API key。该修复解决上述协议读取问题，不改变账号登录状态或其他客户端对同一原生线程的占用。
