# v0.34.33

- 每一轮对话开始前，若任务已添加硬件设备但未保存“AI 使用”授权，会在对话里直接说明本轮不带 Duo 桌面/硬件工具运行、授权从下一轮生效；只读模式也说明不接入控制工具。此前这种情况是静默的，容易看起来像设备掉线或工具失效。
- 判断依据是任务的设备绑定表而不是授权表：只添加设备、没有保存过权限时不会留下授权行。已授权（含被收回）时不重复提示；显式无工具运行（知识整理）不提示。
- 文档补充上述说明与桌面共享的交叉引用。

验证：Go 全量测试与 vet、TypeScript 检查与构建、网页回归通过。新增回归覆盖四种状态：未添加设备保持静默、已添加未授权时点名原因、只读模式点名原因、授权后静默、收回后再次提示，以及显式无工具运行保持静默；均为本地合成夹具，未调用模型、未连接真实设备。

版本说明：v0.34.32 属于同一仓库的并行任务（任务徽标与流式过程记录），其发布流程未成功，本次不覆盖该版本号。
