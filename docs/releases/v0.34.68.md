# Duo v0.34.68

长任务不再只能等到整轮结束才在工作区留下进展。开启自动记录与工作区任务记录后，任务主 Markdown 增加独立的执行快照。

## 执行期间记录

- 引擎开始执行时尝试保存初始快照；执行期间有新事件时最多每 15 秒刷新一次。写入在独立协程进行，不阻塞模型事件流；没有新事件则不重复写文件。
- 快照显示轮次、最后事件时间与序号、引擎与模型、原始需求，以及少量公开进度、用户补充、错误和最新助手文本。累计助手文本只保留最近一份。
- 工具活动只记录时间和事件号，不把工具开始当作成功，也不在快照复制工具参数、原始输出、私有推理或附加记忆 JSON。公开文本仍经过脱敏和有界截取。
- Harness、Codex 原生思考与公开进度分开标记；旧数据库中的通用 `progress` 事件无法可靠重分类，本版不声称清理了过去的事件标签。
- 执行快照、当前任务状态、历史导航分别维护独立的受管区域。快照不会更新目标、计划完成状态或验证结论，不会生成长期知识候选，也不消耗终态历史来源。

## 结束与恢复

- 引擎返回后先取消并等待执行快照写入器退出，再保存终态。正式来源和历史写入成功后，同一次主文档原子写入清除完整的执行快照；失败或停止时也保留已收到的公开进度。
- 任务正在执行时，手动同步历史不会清除执行快照。任务改名沿用既有任务目录。
- 实时快照发现超过 500 个目录且无法确认当前任务原目录时，拒绝猜路径新建，避免改名后重复目录；常规历史发现仍保留既有上限。
- 长文交接时单独压缩执行快照摘录，为已有目标、计划和最近需求保留空间；原 Markdown 和读取进度快照不被压缩改写。
- 自动同步仍遵循磁盘错误退避与冲突暂停。人工修改执行快照时保留原文，其他状态与终态历史可独立保存。
- 活跃轮次保留持久待同步收据。程序重启会将其标为中断并排队补写任务文档，避免旧快照永久冒充正在运行；文件中保留“截至该时间”的提示。补写仍需工作区可访问且自动记录开启。
- Windows 与 WSL / SSH 的文件协议保持同等区域哈希、原子替换、修改冲突和大小保护。轻量快照不重新生成逐轮来源、历史页或知识库索引。

## 边界

这是执行事件的可读快照，不是语义里程碑自动总结，也不是操作成功的独立验证。结构化目标、计划、决策与证据仍在轮次结束后消费合法 `task_state`；持续无公开事件时保留最后快照，不伪造新的进度。

自动跨主题合并与矛盾消解、旧笔记保留身份的正式迁移、真实模型多引擎接续质量验收、无人值守付费提取和向量检索仍未完成。本版不调用真实模型，不自动升级或重启本机 Duo，不移动旧笔记。

## 发布回归

隔离知识库显式同步回归中的后台自动同步，避免首轮自动同步抢先导入导致计数断言偶发失败；保留外部修改降级、导入计数和双侧冲突保护断言。生产自动同步行为不变。
