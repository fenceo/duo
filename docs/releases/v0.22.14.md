# v0.22.14

- Codex 普通执行模式启用原生提问能力。AI 发起问题时，Duo 显示选项、说明及原生允许的自填答案；明确区分“等待回答”和“可以继续工作”的问题。答案直接交回当前原生请求，轮询保留未提交内容，敏感答案不写入 Duo 历史记录。
- 执行中的输入区提供“立即引导”“中断后发送”“排队发送”。立即引导通过原生 `turn/steer` 追加文字到当前轮次；中断后发送先保存新要求，等待当前执行退出，再恢复原会话并优先处理；其他排队消息保留。
- 引导确认后才记入对话，重复请求复用同一次结果，过期轮次拒绝投递。拒绝、断连或无法确认的发送保留输入，不自动改成排队；无法确认旧执行退出时不启动下一轮。
- 立即引导当前支持 Codex 文字输入，沿用本轮模型、工作目录和权限；附件或新的权限选择使用排队/中断后发送。停止按钮仍停止当前执行并取消全部排队消息。

原生提问由模型按需发起，并不保证每个复杂任务都会提问。本轮使用模拟 app-server、HTTP 和网页场景验证，不调用真实模型；不同执行环境中的真实模型提问与引导效果需要日常使用确认。功能开关仅作用于 Duo 启动的 Codex 进程，不修改用户全局配置。
