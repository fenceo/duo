# Duo v0.34.3

- 左侧任务三点菜单新增“分叉会话”：复制分叉前的全部 Duo 历史、关联附件、知识和增量记忆，新任务与原任务分别继续。首次发送通过固定历史归档接续上下文，使用独立原生会话；原任务与原生会话不重置。
- 分叉使用数据库事务，失败完整回滚；不会复制执行队列、待答请求、硬件/桌面授权或飞书绑定。分叉前需结束执行及排队，两个任务仍共享原工作目录。
- 继承的用量在历史中保留，不重复计入全局、每日或任务用量汇总。
- 新增“重新打开任务”和“复制重新打开命令”菜单，以及 `duo-service.exe --data <数据目录> --open-task <任务ID>` 命令；可加 `--print-task-url` 只输出链接。复制命令会填好程序路径、数据目录和任务 ID。命令可在服务运行时使用，不初始化数据库、不重发要求、不重置会话，仍需网页登录。
- 补充 Windows 沙箱工具初始化失败的诊断说明。重新打开任务不保证解除宿主运行程序的文件占用，也不解除其他客户端持有的原生会话写入锁。

升级保留现有任务、账号、环境和数据。回归使用合成运行器与本地夹具，不调用真实模型、不终止用户的 Codex 桌面端。
