# Duo v0.20.16

## 修复 Windows Harness 选模型后仍使用错误 provider

- 修复 v0.20.15 仅替换旧默认模型、却没有为新选择的模型同步解析 provider 的问题。旧环境默认配置现在按实际所选模型匹配本机 DSH provider；显式路由继续优先。
- 使用标准 YAML 解析器读取 DSH 模型元数据，支持普通缩进、行内格式和引号；遵循账号配置与继承的 DSH_HOME，不把 Windows 配置用于 WSL/SSH。
- 不再把 off/low/high/max 当成所有模型都支持的能力。模型未声明推理强度时使用工具默认，切换模型会清除无效强度。
- 刷新模型列表不再重新插入过时的 deepseek-flash 默认项。多个 provider 的同名模型要求明确配置 provider；不会擅自切换到列表里的第一个模型。
- SDK 启动等待上限从 30 秒调整为 60 秒，保留取消响应，超时提示包含实际 provider/model。新增 Windows 原生 initialize/shutdown 诊断，不发送模型提示词。

升级后，新建 Harness 任务并重新选择模型，推理强度先用“工具默认”。旧失败任务及聊天记录保留，不自动重试或产生 API 用量。
