# Duo v0.34.19

- 修复 MiMo Code 在 WSL/Linux 安装失败：官方 0.1.15 tar 包包含 `mimo` 和 AppleDouble `._mimo` 元数据，旧检查误判为多余程序。新检查验证并跳过该元数据，仅提取原生可执行文件；继续拒绝危险路径、链接、重复程序和其他额外文件。
- 安装错误区分版本读取、目录创建、程序下载、解压校验和启动验证阶段，不回显原始错误中的代理信息；原安装保持不变。
- Claude Code 和 MiMo Code 的“配置 API”改为所选环境的独立窗口，与 Harness 的入口方式一致。支持官方/自定义服务预设、接口协议、模型目录验证和直接保存生效，不再要求添加账号库存后激活。
- 验证读取的 MiMo 模型写入原生提供商目录，供新建任务读取和选择；手动默认模型仍会保留。
- 已保存 Key 不回显，留空可保留同一服务的 Key；更改地址、协议或认证方式要求重新填写。保存前检查执行/排队状态，保留原文件备份、权限与其他配置；环境保存失败会回退原生文件。MiMo 继续保留原生会话数据目录，兼容已激活的旧库存配置，不删除旧账号或任务记录。

实际 WSL 隔离验收已通过官方下载、安装包解压、原生版本检查和 API 文件助手读写，未改变用户现有 CLI、配置或账号，未发送模型请求。API 配置的认证/模型目录验证不等于真实推理验收。使用说明见 [Claude Code 与 MiMo 配置](../claude-mimo.md)。

验证：Go 全量测试及 vet、TypeScript 检查与构建、40 项网页回归和 133 个桌面/窄屏界面用例通过。新增回归覆盖原生配置保存生效、已保存 Key 的目标隔离、旧库存引用变化、模型目录写入、账号来源标记清理、失败回退与压缩包边界。

云端验收发现原生 Windows 终端测试在 PowerShell 输入循环就绪前发送首条命令，导致等待输出超时。测试改为先等待真实提示符；输入、尺寸、中文、打断与退出检查仍保留，连续十次本地回归通过。
