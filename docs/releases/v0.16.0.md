# v0.16.0

任务切换模型时重新读取当前环境的模型目录，并在更新页面直接下载、校验和替换程序。

## 修复：任务模型列表

- 每次打开任务底部的模型菜单都会重新读取模型目录，不再沿用第一次读取到的空列表或失败结果。
- 合并该环境返回的模型、环境默认模型和任务当前模型，去重后一起显示。
- 模型目录暂时读取失败时仍可直接输入模型名称，按 Enter 保存，不影响继续切换。

## 新增：Windows 便携版自动安装

- “设置 → 版本更新”检测到新正式版本后，可直接点击“下载并自动安装”。
- 下载包限制为 256 MiB；优先校验 GitHub Release digest，也兼容同版本 `.sha256` 文件。
- 安装前校验 ZIP 白名单、文件大小、重复项、路径穿越和 Windows PE 文件头。
- 更新助手等待托盘和数据锁退出，备份旧程序后替换两个 EXE 与两个说明文件，再启动新版。
- 新版启动后会检查 `/healthz` 和实际版本。检查失败会自动停止新版、恢复备份并重新启动旧版。
- `data` 数据目录不参与替换，更新日志写入 `data/update.log`。

## 第一次升级说明

`v0.15.0` 尚未包含自动安装代码，因此从 `v0.15.0` 升级到本版仍需手动下载并替换一次。完成后，从本版开始的后续正式版本可以直接在设置中自动安装。

## 下载

下载 `Jianzuo-portable-windows-x64.zip` 后完整解压，双击 `简作.exe`。`Jianzuo-portable-windows-x64.zip.sha256` 用于校验下载完整性。升级时保留原来的 `data` 文件夹。
