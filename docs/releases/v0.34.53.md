# v0.34.53

## 飞书动态任务操作菜单

飞书原生机器人菜单是应用级静态配置，无法按任务状态切换。本版改为**动态任务操作卡**：点菜单后按「是否已进入任务」返回不同按钮，效果等同于随任务变化的菜单。

### 菜单（三项）

| 菜单 | 作用 |
|---|---|
| **任务操作** | 打开动态操作卡（按当前状态变化） |
| **新建任务** | 提示直接发送要求即新建并执行 |
| **我的任务** | 任务列表，可选择/切换 |

### 动态操作卡

- **未进入任务**：「＋ 新建任务」「任务列表」
- **已进入任务（空闲）**：「▶ 继续执行」「查看详情」「整理知识」「切换任务」「退出任务」
- **已进入任务（执行中）**：「停止执行」（替代继续，带轮次校验）+「查看详情」「整理知识」「切换任务」「退出任务」

### 在外面通过飞书使用

手机上打开飞书即可：点「新建任务」发要求建任务；点「任务操作」看当前任务并继续/停止/切换；点「我的任务」在任务间切换。终端、文件浏览、Git 差异仍需网页访问。

## 使用说明

- 升级后重启一次 Duo 服务，飞书菜单刷新为新三项。
- 「任务操作」卡片按钮会随任务绑定状态和执行状态变化。
- 直接发送要求文字始终可用：未选任务时新建并执行，已选任务时继续当前任务。
