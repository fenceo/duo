# Duo v0.20.7

## 新建任务上下文

- 环境选择明确显示 Windows、WSL 或 SSH；SSH 使用设置中预先配置的主机、端口、用户和密钥/ssh-agent。
- 切换环境时，工作目录候选、浏览目录和路径提示同步切换；任务会保存环境与目录快照。
- 首次任务和已有任务对话框都支持直接粘贴截图或图片，图片会进入附件上传流程。

## 工具与模型

- 设置中的环境检测展示 Codex、Claude Code、DeepSeek Harness、Kimi Code 和 MiMo Code 的已安装/未发现状态。
- AI 引擎页提供对应的安装/配置指南和官方文档入口；Duo 不读取或保存 CLI 密钥，也不会未经确认执行联网安装。
- 模型列表始终按目标环境、工作目录和当前工具读取。Codex 优先使用目标 CLI 的原生目录与当前账号/API 配置；Harness 显示其已配置的 provider/model，并通过“测试列表模型”验证实际可用性，不猜测 provider 未公开的模型。

## 验证

- TypeScript 检查、Web 回归测试、Go 测试、启动器/安装器测试均通过。
