# v0.31.1

- 简化账号管理：Codex / Claude 账号卡片统一使用「切换到环境」，勾选 Windows、WSL 或 SSH 后直接更新目标原生登录和 API 服务配置；保留原文件备份。
- 移除「仅此任务使用」、任务账号选择及跟随/固定账号模式。账号切换不读取或修改对话、任务、原生会话 ID、模型和排队消息，也不自动创建新会话或转交历史。
- 任务运行和模型列表统一使用目标环境的原生登录，旧任务中保存的账号引用不再覆盖该环境的登录。旧记录保留，不按账号重新分配或迁移任务。
- 账号卡片显示上次切换到的环境；旧版只改变 Duo 默认引用的记录不冒充已经写入原生登录。移除账号引用保留已写入环境的登录文件。
- 保留跨引擎、执行位置切换时的任务历史接续；单纯切换账号与此功能无关。已运行 CLI 是否即时读取新登录由原生工具决定，必要时重新打开。
- 合成回归覆盖原生文件切换、活动/排队任务保持、会话 ID 保持、旧绑定不参与登录和无历史接续副作用；未使用真实账号或模型。
