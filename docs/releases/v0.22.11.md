# v0.22.11

- 压缩左侧任务栏：顶部显示 Duo 图标和实际服务版本，下面保留新建任务、搜索与任务列表。
- 全局知识库、设置、外观及退出移到右上角工作台菜单；版本号可直接打开更新页。工作目录仍在新建任务时选择，常驻连接成功提示移除，断线时仍显示重试提示。
- 左下角新增默认展开的共用便签：无需先选任务，可直接编辑、勾选完成、删除后撤销、添加事项和切换五种颜色。输入停止后自动保存到 Duo 数据库，支持中文输入法和多行内容。
- 自动保存失败时保留草稿并提供重试；多窗口版本冲突不会静默覆盖；刷新列表不会打断正在编辑的内容。便签随工作区导出脱敏并支持追加导入。
- 原有任务待办数据保留，可从右上角“会话 → 本任务待办”访问。便签不会自动发送给 AI，也不作为任务知识自动补回。
- 手机端便签留在左侧任务抽屉，避免常驻占用对话高度；手动设置的面板位置仍然保留。

已保存便签由同一 Duo 服务下的浏览器共用。未保存草稿仅在当前页面内存中，关闭或刷新前会提示；遇到版本冲突应先复制需要保留的内容，再重新加载。

本版包含 v0.22.10 的长对话输入性能修复。
