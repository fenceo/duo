# v0.33.0

- 修复桌面预览点击无反应：旧版只有截图展示，未连接网页输入事件；新增「我来操作」，允许通过预览单击、右键、滚轮操作。可选择双击模式，发送普通字符、快捷键或中文文字。
- 人工控制使用独立的浏览器授权，不改变 AI 只读/可控设置。人工控制期间暂停 AI 桌面操作；结束后 AI 必须重新观察。关闭面板、隐藏网页或按 Escape 结束人工控制，断开后 60 秒无刷新会自动释放；停止共享仍撤销整个授权。
- 坐标按原始截图尺寸映射，兼容预览缩放与负坐标多显示器。近期画面元数据有数量与有效期限制，刷新不抢走刚显示的画面；动作串行执行，旧画面不能重放，失败不自动重试。仍保留目标窗口前台、位置、权限和共享范围检查。
- 人工模式约 1.2 秒刷新一次 PNG。不是 AHA2 全套共享逻辑移植，本版未加入拖拽、自适应视频传输、后台控制或隔离桌面；共享窗口仍需保持前台。
- 新增网页、授权与并发合成回归，并扩展一次性 Windows CI 窗口测试。未对用户真实桌面自动操作，也未调用真实模型。
