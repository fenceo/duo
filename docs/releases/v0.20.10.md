# Duo v0.20.10

## 更新检查可靠性

- 修复 GitHub API 使用未来版本标识导致部分网络出口、代理或网关拒绝请求的问题，改用已发布的稳定 API 版本。
- GitHub API 返回 403/429 限流时，自动回退到公开 Release 页面读取最新正式版本，不再必须等待 API 配额恢复。
- 更新界面现在会区分 API 配额耗尽、Retry-After 和普通限制，并在有响应头时显示预计恢复时间。
- 回退路径只使用仓库 Release 页面和固定的 Duo 安装包/便携包文件名；下载仍经过原有 GitHub 主机白名单、大小和 SHA-256 校验。

## 发布文件

- `Duo-Setup-User-x64.exe`：Windows 安装版，支持新装和原位升级。
- `Duo-portable-windows-x64.zip`：Windows 便携版。
- 两个文件均提供 `.sha256` 校验文件。
