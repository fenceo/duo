# v0.34.6

修复 WSL 一键安装 DeepSeek Harness 在缺少 Linux Node.js、只找到 Windows npm 时直接失败的问题。该改进也适用于 WSL/SSH 的 Codex 和 Claude Code 安装。

- 缺少可用原生 Node.js/npm 或只找到 Windows npm 时，自动下载并校验 Linux x64/arm64 独立运行时。
- CLI 入口携带运行时路径，后续任务无需交互 shell 加载 nvm。
- 分别提示运行时下载/校验、npm 网络/权限/磁盘空间和 CLI 启动失败；仅在验证成功后保存环境工具路径。
- 安装回归固定模拟工具的优先级，避免宿主 shell 重写 PATH 后误用系统程序。
- 目标环境仍需具备 curl、tar、sha256sum，并能访问 Node.js 和 npm 官方站点。不使用 sudo，不改账号或 shell 配置。
