# v0.34.5

修复 WSL 一键安装 DeepSeek Harness 在缺少 Linux Node.js、只找到 Windows npm 时直接失败的问题。该改进也适用于 WSL/SSH 的 Codex 和 Claude Code 安装。

- 检查原生 Node.js/npm，复用可用的 Node.js 22 或更新版本；缺失或不兼容时，在目标用户的独立目录下载并校验 Linux x64/arm64 Node.js 24.19.0。
- 保存带运行时路径的 CLI 入口，后续任务不依赖 Windows npm 或交互 shell 的 nvm 设置。
- 区分连接、运行时下载和校验、npm 网络/权限/磁盘空间及 CLI 启动失败，不回传可能含凭据的安装输出。
- 不使用 sudo、不改变目标用户、不覆盖已有全局 CLI、账号或 shell 配置。启动验证成功后才保存环境工具路径。

目标环境需具备 curl、tar、sha256sum，且能访问 nodejs.org 和 registry.npmjs.org；其他系统/架构需自行准备原生 Node.js/npm。
