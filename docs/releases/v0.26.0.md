# Duo v0.26.0

- 新增 Codex 登录同步：在设置 → AI 引擎中选择一个 Codex `codex_home` 配置，再勾选 Windows、WSL 或 SSH 目标环境。
- 同步只读取来源目录的 `auth.json`，目标已有文件会先保存为 `auth.json.duo-backup`，再通过临时文件替换；不会改写 `config.toml`。
- WSL 和 SSH 的凭据通过标准输入传输，不出现在命令行参数、Duo 返回值或日志中。每个目标单独返回成功或失败状态。
- 已运行的 Codex app-server 不会被强制停止；同步完成后需要重启它才能读取新账号。图片、任务数据和其他环境配置不受影响。

验证：TypeScript 检查和网页构建通过；Codex 同步合成测试通过。全量 Go 测试仍受现有 Vault 权限测试及模型取消测试失败影响，未将其报告为本轮功能通过。
