# v0.24.1

- “切换继续”升级为“切换 AI”：在当前任务选择引擎、账号/API 配置、模型和权限。保留聊天、知识和草稿；确认切换不立即调用模型，下一条消息开始接续。
- 相同引擎和账号仅换模型时沿用原生会话。跨引擎、账号或执行位置时使用新原生会话，附带接续摘要和完整所选历史文本，可按需查阅较早对话、引导消息和工具记录；不再只转交最近 8/20 轮或另建任务。
- 每个任务固定配置引用，排队消息固定提交时的引擎、模型和引用。全局账号默认只影响新任务。模型目录和任务内模型测试使用实际绑定，旧回复保留原引擎标签。
- 对切换增加运行/排队拦截、预览与账号版本检查、重复提交保护和事务回滚；失败时保持原记录。支持直接管理账号配置、全文脱敏预览和手机布局。
- 顶部移除“会话信息”“复制链接”，保留在左侧任务菜单。

旧版本的原生会话没有可靠的账号绑定，升级后首次继续请点击“切换 AI”确认配置，通过新会话接续历史。不同 API/账号请使用独立原生配置目录；Duo 不迁移密钥、原生 session 或图片附件。同目录中的外部账号变动仍由引擎管理。

完整所选历史以文本文件供模型读取，摘要有长度限制，不能保证模型已阅读所有历史。单次历史超过 64 MiB 时明确提示，不静默截断。真实模型、第三方 API 兼容性和远端接续效果未在本轮实测；验证使用合成数据与隔离测试，不改动或重启正在使用的 Duo。
