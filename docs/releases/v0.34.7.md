# v0.34.7

为 Windows / WSL / SSH 环境的 DeepSeek Harness 增加 API 配置入口，并修复远程 ACP 启动脚本的缩进错误。

- 设置 → 环境与引擎 → 对应环境的 Harness → 配置 API，可填写 API 根地址、模型 ID 和 Key，选择 Chat Completions、Responses 或 Anthropic Messages 协议。
- 按所选环境用户写入 Harness 原生 `cordis.patch.yml`；Key 单独写入 version 1 的 `.credentials.yaml`，不写入 Duo 配置、命令参数或响应，不回显。修改时留空保留 Key。
- 原文件先备份，保留其他提供方、模型、工具和凭据。参与原生文件锁并检查文件快照；目标环境变化时拒绝保存，Duo 配置保存失败时尝试恢复原文件。
- 保存环境默认 provider/model，不修改会话或任务绑定、不自动测试模型。新启动的 Harness 读取配置；已运行的会话可能需要重新打开，独立配置目录需在对应 Harness 中管理。
- 一键安装的是官方 `dsh` CLI；Duo 通过 ACP stdio 调用它，由 Harness 请求模型 API。
- WSL 原生隔离回归已验证新配置、凭据读取和完整 ACP 回复，使用本地模拟服务与合成 Key，不消耗模型额度。

此入口管理所选用户的默认原生目录（`DSH_HOME` 或 `~/.dsh`），适配安装的 Harness 0.2.0 配置格式。目标环境使用自定义凭据存储时，应在 Harness 中管理该存储；WSL/SSH 需 Python 3。
