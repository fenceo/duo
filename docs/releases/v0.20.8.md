# Duo v0.20.8

## 任务链接与跨引擎续作边界

- 任务页和任务菜单新增“复制链接”，复制的是 Duo 本地任务链接（`/?task=...`），打开后仍需在运行 Duo 的主机上登录。
- 链接不包含原生会话 ID、工作目录、API 密钥、SSH 私钥或其他凭据；它用于定位 Duo 任务，不等同于 Codex 官方 `codex://` 会话链接。
- 本版本明确区分“同一引擎继续”和“跨引擎转换”：Codex/Claude 的原生会话只在原执行环境和可见账号配置中继续，DeepSeek Harness 目前只支持当前进程内继续。
- Codex → Harness 等跨引擎续作将在后续版本以“转换分支”提供：创建新的原生会话，经过脱敏预览后注入任务摘要、最近对话和已验证知识，原任务保持不变。

## 安全与升级

- 继续保留现有数据、任务、知识和环境配置；复制链接不会导出数据。
- 升级包仍为安装版 EXE、便携 ZIP 及各自 SHA-256 校验文件。
