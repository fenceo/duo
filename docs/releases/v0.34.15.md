# Duo v0.34.15

- “环境与引擎”检测后显示 Codex、Claude Code 和 Harness CLI 的当前版本，并提供“更新 CLI”。支持已配置的 Windows、WSL 和 SSH 环境，安装官方 npm `latest` 渠道版本；具体是否为预发布版本由上游渠道决定。
- 更新安装到独立目录，验证新 CLI 版本后才切换路径；下载、验证、取消或配置冲突导致失败时保留原配置和原安装。更新该环境的引擎前需结束执行和排队任务，更新期间暂不接受该环境、该引擎的新任务。
- 同一目标中使用原 CLI 路径的旧任务，下次执行会跟随已验证的更新链；自定义路径、其他目标及手动改过的路径不被替换。保持原生账号、会话和模型配置；Harness 空闲会话使用现有关闭/恢复流程换用新 CLI。
- 设置保存与更新激活增加并发保护：旧页面不能把已更新的路径覆盖回去，也不能伪造更新链。更新完成时保留未保存的设置草稿及新版 Harness API、图片能力配置。
- 本版仅包含 CLI 更新相关功能，不包含先前讨论的 Codex 进程清理修复；不更改 Codex 的启动、终止或进程树管理方式。

使用方式：打开“环境与引擎”，点击“检测”，在目标引擎行点击“更新 CLI”；进度区可取消。更新失败可查看提示后重试；已打开的旧设置页提示冲突时重新打开设置。

已通过完整 Go 测试、vet、38 项网页回归和 115 个桌面/手机尺寸用例。验证使用合成安装器、测试进程和回环服务，不调用真实模型，不替用户升级实际 CLI 或重启正在运行的 Duo。
