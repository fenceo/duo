# v0.34.61

- 新建任务填写独立名称，工作区任务目录改为任务名加稳定短标识；未修改的旧生成目录可安全迁移，保留旧链接与分叉来源，人工编辑不被覆盖。
- 输入框的模型选择器整合 AI 引擎切换；自动准备历史文件及交接提示，保留记录和草稿。异常会话重建移到高级恢复。
- 任务菜单新增任务记录与知识，支持直接阅读交接摘要和逐轮 Markdown。
- 平台共识、系统知识、项目知识可从普通回复自动提取待验证候选；可一键整理已有候选，或明确确认后以独立 AI 会话重新整理最近有限历史。
- 一个 Obsidian 根目录下支持三个自定义相对目录，保存时创建；知识带标签、来源、依据与适用条件，保留安全迁移与冲突保护。
- 三类知识直接出现在主菜单，可查看、编辑，并以标签关系图谱浏览。

自动提取不追加模型调用，也不自动确认知识已验证。手动 AI 提取会发送最近最多 8 轮成功对话的有限文本，消耗模型额度；目前支持 Codex、Claude Code、Harness。跨电脑同步由外部 Git 客户端负责。未自动安装或重启本机 Duo。
