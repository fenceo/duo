# v0.34.11

继续补齐 DeepSeek Harness 的原生会话能力，接通文件和图片附件。

- Harness 新建任务与会话支持选择文件、拖放和粘贴图片，复用原有附件上传、排队、撤销及目标环境暂存链路；不再一律拒绝附件，也不会删除切换引擎前选中的草稿。
- 单个不超过 256 KiB、合计不超过 512 KiB 的 UTF-8 文本直接作为资料内容进入原生会话，包括跨引擎接续的历史文件。超额或二进制文件保留目标环境路径，由 CLI 按原权限读取，不截断后冒充全文或已读取结果。
- PNG/JPEG/WebP/GIF 使用 ACP 原生图片块。要求 CLI 握手和所选模型声明图片输入能力；文本模型或旧 CLI 明确拒绝，不将图片降级为路径继续发送。
- 文本连接切换到图片模型时正常关闭并恢复同一个原生会话，保留历史和原进程账号目录。图片由 Harness 持久化，临时附件清理后仍可在原生历史中恢复。
- 不新增 ACP 客户端文件或终端权限，不改变既有审批和执行环境。硬件工具、独立知识总结及 Codex 自动风险评审仍未接入 Harness。

已使用安装的官方 `dsh 0.2.0-rc.2`、隔离 WSL 用户临时目录和回环模型验证文本、图片、模型切换、原生历史恢复以及文本模型拒绝图片；未调用付费模型。现有任务、账号和环境配置不迁移。图片能力取决于服务商和 Harness 原生模型配置，并非所有 DeepSeek 模型都支持图片。
