# Duo v0.20.15

## Windows Harness 路由修复

- Windows 端使用 DeepSeek Harness 时，会读取当前 DSH `settings.yaml` 中的 provider/model 列表。
- 当 Duo 仍保存旧的 `deepseek-official/deepseek-flash` 默认值时，自动使用本机已配置的 provider 和模型，例如 `hl/deepseek-v4.1-flash`。
- 模型选择器与实际 Harness 启动共用同一条路由解析逻辑；显式 provider/model、WSL 和 SSH 配置保持原样。
- 只读取 provider/model 标识，不读取或复制 API key 等凭据。
