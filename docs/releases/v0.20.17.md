# Duo v0.20.17

## Harness 模型切换与原生会话恢复

- Harness 接入改为原生 ACP，任务空闲时可直接切换模型或推理强度，同一个任务和原生会话继续使用；换模型自动清除旧模型的推理强度覆盖。
- 停止当前轮、闲置回收进程或重启 Duo 后，下一条消息通过 Harness 的持久化记录恢复原生上下文。30 分钟只是释放闲置进程的时间，不再是会话失效期限。
- 旧 SDK 任务继续使用原会话 ID 尝试原生恢复。原生文件缺失或账号目录不匹配时明确报错，保留任务与聊天记录，不静默清空上下文或重放网页聊天记录。
- 修复冷启动时 ACP 已可连接、模型配置插件尚未就绪造成的 provider 未注册错误；仅在创建/恢复会话阶段短暂重试，不重发模型请求。
- 修复旧权限快照因名称、默认值格式变化而被误判为权限变更；保持原有实际权限边界。执行中或排队中的任务需先停止或结束后切换模型。
- 更新模型菜单、停止操作和会话状态提示。模型列表不再插入原生目录中不存在的旧默认项。

需要目标环境的 Harness 提供 ACP v1、session/resume 和 session/close。已使用本机 dsh 0.1.5-rc.2 与隔离的回环模拟模型验证旧 SDK 会话迁移、模型切换、闲置回收、重启和取消后的上下文恢复；测试不读取用户凭据或消耗付费 API 额度。原生恢复需要原执行环境、原账号目录及完整的 Harness 会话文件。

发布包含 Windows 安装程序、便携 ZIP 及两份 SHA-256 校验文件。
