# Duo v0.22.0

- 默认自动记录后续成功对话的要求与最终回复，保留任务与执行来源，标为待验证，无需点击“沉淀为知识”。网页和飞书均适用；不增加模型调用。
- 相同任务内未截断且完全相同的问题与回复去重；失败、中断、空结果和独立知识总结草稿不自动保存。人工编辑、验证状态和删除操作不被重复完成回调覆盖。
- 开启新的原生会话时，自动补回当前任务最多 3 条知识，优先已验证条目，再取近期记录；每条正文最多 1200 字，过时知识和其他任务不带入。正常原生续聊不重复注入。
- 知识库新增“对话自动积累”设置，可分别关闭记录或恢复；关闭保留已有知识。完全空白会话需要先关闭自动恢复。
- 自动记录默认仅保存在本机。Vault 新增独立导出开关，默认关闭，保持原有人工结论的同步范围。已导出的文件不会因关闭开关而被删除。

迁移：只影响升级后完成的对话，不回填旧记录。保存的是本轮要求和最终回复，经常见凭据脱敏并受单条容量限制；不是语义提炼，不自动判断真伪或合并相似结论。自动恢复使用有限的任务知识快照，不代表完整重放历史，会增加本轮输入 token。跨任务使用仍通过知识库显式引用。
