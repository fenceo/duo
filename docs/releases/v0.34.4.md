# v0.34.4

Windows Codex 沙箱初始化在打开已运行的工具文件时可能遇到文件共享冲突，导致命令在启动前失败。Duo 现在会检测本机 Codex 是否支持 MXC，并在受限任务中优先使用该隔离方式，减少对旧 ACL 初始化路径的依赖。

- 仅对本机 Windows Codex 生效；WSL、SSH、旧版不支持 MXC 的 CLI 和显式完全访问模式保留原启动方式。
- 尊重所选 `CODEX_HOME` 或项目配置中的 `features.prefer_mxc=false`；不改写 Codex 配置或账号文件。
- 文件、网络和审批权限保持任务原有设置；MXC 的设备适配、管理策略及旧沙箱回退由 Codex 自身执行。
- 原生请求或轮次遇到已知 Windows 沙箱初始化错误时，保留原始诊断并提示检查版本、运行文件占用和设备策略；不重放请求、不更换会话。

此修复集成了官方 MXC 兼容路径，不替换或修补 Codex 自带的旧沙箱二进制。MXC 不可用时，旧实现仍可能需要更新 Codex 或处理设备策略。
