# v0.34.65

- 任务记录不再依赖一段短摘要：按轮次展开原始需求、助手结果、执行事件、时间、状态和来源；长文保留开头与最终结论。没有有效结构化状态时明确资料缺口，不把一次提问当作持续任务目标。
- 历史稀疏记录通过独立来源标记一次性补充细节，不重写旧记录与人工正文。仅精确匹配旧默认模板时移除误用问候的目标；手工改过的目标、计划与备注保留。
- 可读知识布局在项目/主题下生成阅读手册，汇集已有正文、适用条件、依据、状态和原笔记链接，过长自动分页。三类知识默认浏览优先显示手册；原笔记身份、修订和编辑入口保持独立，汇编本身不产生新的已验证结论。
- 知识列表显示正文摘要与项目，路径和来源放进折叠详情；任务标题显示 Markdown 标题，长文支持章节导航和文首/文末定位。同工作区任务可直接打开，未保存草稿与过期异步结果保持隔离。
- 修复编码中文相对 Markdown 链接和页内章节定位，拒绝目录越界与重复编码；阅读手册中的常规来源链接按原笔记位置重定向，代码示例保持原文。
- 项目检索增加项目范围限制，避免仅凭 AI、架构等通用标签混入无关项目；明确引用其他项目时仍允许查询。检索继续使用有界关键词匹配，不是语义搜索或事实复验。
- 后续知识提取按可独立阅读的问题/主题组织，要求已有背景、方法、原因、结果及适用边界，避免拆成多条一句话笔记；没有资料时不补造内容，同主题优先进入待合并修订。
- 离线整理工具默认生成“每任务一份档案 + 分页月日志 + 主题阅读手册”，保留知识原文与原件哈希，支持由知识直达对应轮次的结果和失败信息。脱敏或已缺失的原引用显示原因及原路径，不生成无法恢复的文件链接。输出为独立阅读视图，不自动创建正式知识条目或切换数据库配置；旧逐条布局可显式选择 `--layout source-notes`。

任务主文档仍有 1 MiB 上限，状态在每轮结束更新，尚无逐工具事件实时检查点。自动/一键/定时整理仍只处理已保存候选，语义重写旧聊天需要明确触发 AI 整理。未自动安装或重启本机 Duo，未更改正式笔记路径，未调用真实模型验证语义提取质量。
