# v0.34.50

## DeepSeek V4.1 适配提示

- DeepSeek 官方 API 预设提示更新为 V4.1 系列模型（`deepseek-v4.1-flash` / `deepseek-chat` / `deepseek-reasoner`）。
- 标注 **Search / Fetch 工具单独计费**（与模型 token 分开结算）。
- Harness 升级指引：官方建议 V4.1 搭配 `@deepseek-ai/dsh 0.2.1-rc.1+`；Duo 的「更新 CLI」会安装官方最新版并验证后切换。
- 添加 API Key 弹窗、Harness 配置 API、环境模型占位同步更新为新模型 ID。

## 使用说明

- 已有 `deepseek-flash` 等旧模型 ID 继续可用，无需强制迁移。
- 在环境与引擎 → Harness 行点「更新 CLI」可升级到官方最新 dsh。
- Search / Fetch 费用与模型 token 分开，可在 DeepSeek 控制台单独查看。
