# v0.34.51

## 飞书端新建任务

- **直接发要求即可新建任务**：未选择任务时，发送任意要求文字会自动新建任务并开始执行，标题自动截取。
- **命令别名**：`新建` / `新建任务` / `新任务` / `/新建任务` 均等价于 `/新建`；`帮助` / `停止` / `知识` 等也支持不带斜杠写法。
- **`/新建 要求` 单参数**：自动取标题；`/新建 标题 | 要求` 仍可显式指定标题。
- **机器人菜单新增「新建任务」**：与「我的任务」「整理知识」并列，点击后提示直接发送要求。
- **任务列表卡片新增「＋ 新建任务」按钮**。
- **空工作目录防护**：未配置工作目录时给出明确提示，不再越界。
- 未选任务时的「继续 / 停止」仍要求先选择任务，不会误建任务。

## 使用说明

- 飞书私聊直接发「帮我检查串口日志」即可新建并执行。
- 指定标题：`/新建 串口排查 | 帮我检查串口日志`。
- 旧的 `/新建 标题 | 要求` 用法保持不变。
