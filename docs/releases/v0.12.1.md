# v0.12.1

界面布局可以手动调整并记住，主要给经常同时看对话、任务工具和串口的人用。

- 任务侧栏右边缘、工具面板左边缘、便签板上边缘、硬件调试的发送区上边缘都能用鼠标拖动。
- 双击把手恢复该面板的默认大小；聚焦把手后可用方向键微调，Home 或 Enter 恢复默认。
- 侧栏宽度和工具面板宽度并入界面设置，新增“工具面板宽度”滑杆和“恢复默认布局”按钮。
- 布局存在当前浏览器里，同一台电脑的另一个浏览器不受影响。
- 窄于 760 像素的窗口沿用手机布局，不显示把手。
- 修复构建脚本：非 UTF-8 代码页下编译启动器时，中文文件名会让打包中断。

## 下载

下载 `Jianzuo-portable-windows-x64.zip` 后完整解压，双击 `简作.exe`。`Jianzuo-portable-windows-x64.zip.sha256` 用于校验下载完整性。

已有用户：先退出程序并备份 data，替换程序文件时保留 data。布局保存在浏览器本地，升级不需要迁移。
