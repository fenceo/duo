# Duo v0.34.25

修复长会话点击“分叉会话”时因接续历史超过 64 MiB 而失败的问题。

- 分叉完整历史按最多 4 MiB 的 UTF-8 分卷保存，不再依赖单个 64 MiB 历史文件，不省略早期对话、工具记录或任务资料。
- 续聊自动提供历史目录及分卷路径，核对分卷顺序、总字节数和 SHA-256。文件准备失败或历史不完整时停止启动模型并清理临时文件。
- 分叉及历史分卷在同一数据库事务中保存，失败会完整回滚。原会话、原生登录、配置与历史保持不变；分叉后的新消息分别保存。旧版单文件接续历史继续兼容。

验证使用合成超大历史、中文跨卷数据及模拟执行器，覆盖超过 64 MiB 的分叉、完整性、失败回滚和文件清理；不调用真实付费模型。切换 AI 的完整历史预览仍使用现有 64 MiB 上限。
