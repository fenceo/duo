# v0.23.1

- 知识库改为直接阅读文档：任务资料、通用知识、主题索引及全部文档；日常界面去掉验证状态操作，保留旧资料与旧标记。
- 未配置时默认在运行数据目录下建立 `knowledge/Duo/`。每任务一个稳定文件夹，保存摘要、前提与共识、对话目录和逐轮记录。根目录有 `README.md`，文档使用相对链接。已有关闭设置和同步范围保留。
- 正常模型轮次顺带提取进展、前提、共识、未决问题及有依据的通用知识，不额外启动模型；自动添加标签、生成主题索引。缺少合法整理结果时只保存原记录，不伪造摘要或事实。旧对话不自动消耗模型补做摘要。
- 支持全文分段阅读、相对来源跳转和 Markdown 下载。引用保留长度预算、来源及版本校验，先加入草稿；其他任务资料不自动发送。
- 修复脱敏规则误删 `https://` 来源链接。逐轮文档补入执行中追加的用户消息，工作区导出/导入保留结构化摘要。
- 输入框上边缘可拖动、方向键调整、记住高度及双击复原。侧栏/工具栏拖动按绘制帧合并更新，便签批量测量，拖动期间暂缓轮询。合成回归中 100 次同帧移动只更新一次尺寸。
- 后台文件扫描复用未变化的解析结果，空闲同步不反复改写 SQLite 索引。外部 Markdown 与新生成内容冲突时保留两端。

测试使用模拟模型、临时目录与合成浏览器数据，不调用真实模型、不安装或重启现有服务。真实模型是否遵循可选整理格式、知识是否正确仍取决于模型和来源证据；Duo 不独立认证结论。同轮整理与自动补回会增加当前轮次的 token。
