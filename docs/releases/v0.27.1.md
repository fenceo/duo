# v0.27.1

- 独立账号管理入口：Codex 登录、Codex/Claude API 添加和已有环境账号目录引用集中管理，和引擎安装分开。
- Codex / Claude 账号可以从 Windows、WSL 或 SSH 源同步到所选目标，连同当前 API 地址和默认模型一起切换；保留备份，避免将旧中转站路由留给新账号。仅支持明确的文件凭据类型，不复制原生会话或系统钥匙串。
- 所有已配置环境支持 CLI 检测。Codex、Claude Code、Harness 支持在 Windows / WSL / SSH 安装；远端使用已有 npm，在用户独立目录安装并检查版本，不覆盖原有全局安装。
- 异步提问与桌面 MCP 的现有接口继续保留，并纳入本轮回归。桌面共享使用独立临时授权，与硬件调试共用任务 MCP 传输层。
- 手机侧栏账号与安装入口保持 44 像素触摸尺寸，避免被通用按钮样式覆盖。

WSL/SSH 需预先配置连接；安装需 Node.js/npm，账号同步需 Python 3。同步后重新打开目标 CLI；已有 Duo 任务通过“切换 AI”重新绑定。真实目标账号、远程安装与中转站模型调用未作为例行测试执行。
