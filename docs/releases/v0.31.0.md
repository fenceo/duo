# v0.31.0

- 账号默认跟随执行环境：切换 Windows、WSL 或 SSH 环境的当前引擎账号后，相关任务从下一轮开始统一使用，包括未开始的排队消息；正在执行的一轮继续使用原账号。
- 保留「仅此任务使用」覆盖，并可在「切换 AI」中恢复「跟随环境账号」。任务标题旁显示账号模式，模型列表使用下一轮的账号。
- 账号变化时自动建立新会话，用完整任务历史和摘要接续，包含上一轮刚完成的回复；相同账号后续轮次继续原生会话。
- 原生账号同步完成后自动更新环境选择；目标环境同一引擎存在运行或排队任务时拦截文件同步，保护运行中的账号。外部 CLI 仍需重新打开。
- 升级迁移没有手动切换记录的旧任务为跟随环境，有手动切换记录的任务保留单独指定。账号归属不明的旧原生会话仍须明确确认。
- 新增账号切换、排队接续、迁移、隔离、回滚和同步保护合成回归；不调用真实模型或真实账号。
