# Duo v0.20.1

**[下载 Windows 安装包（新装／升级通用）](https://github.com/fenceo/duo/releases/download/v0.20.1/Duo-Setup-User-x64.exe)**

## 模型列表操作

- “重读模型列表”和“测试列表模型”均放在模型下拉面板内；重读只获取当前环境、引擎和账号的模型目录，不自动调用模型。
- 测试改为检查本次列表中的各个明确模型 ID，确认框列出环境、引擎、模型及数量。测试可能消耗额度，取消确认不会发送请求。
- 逐项显示测试进度与成功、失败、超时结果；可停止剩余测试。网络中断不伪装成模型不可用，未完成项保留未验证状态。
- 停止不会撤销已经提交给服务商的请求，已发出的请求仍可能计费；测试不附加任务对话或附件，但原生 CLI 仍可能加载工作目录的项目指令。
- 切换环境、引擎、目录或账号后不沿用旧测试结果；结果仅代表本次调用，不保证后续余额或权限。
- 单批最多 24 个模型；超出时明确拒绝，不默默截断。空列表不会自动扩展成未知范围的调用。

## 数据与验证

- 升级默认保留原数据，本版不变更安装器的数据选择方式。
- 更新第三步显示已等待时间和最多 180 秒的确认期限，明确这不是安装器实时进度；断线超时提供启动程序和两份升级日志的排查入口，不把旧版本在线误判为升级成功。
- 安装器强化安装归属探测的结果校验和诊断；缺失或无效结果不再默认为“未安装”，仍严格保留目录和所有权保护。
- 自动化与浏览器验收使用合成模型响应，不发送真实付费测试消息。
