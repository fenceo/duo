# v0.28.1

- 账号管理新增「Cockpit Tools 导出 JSON（可批量）」：先解析预览名称、类型和兼容性，再勾选导入。
- 支持 Codex 的平铺订阅令牌、旧版 tokens 账号、API / 中转站配置，以及 Claude Code 的 OAuth / Setup Token 和 API 账号。
- 保留可识别的 API 地址、凭据类型与默认模型。管理器专用网关、模型映射、桌面专用身份等无法直接迁移的条目显示原因，不影响其他有效条目的选择。
- 批量导入创建独立副本，不自动切换默认账号；保存失败回滚本次新建内容，重复提交不会重复创建或覆盖已刷新的凭据。
- 原生 JSON 和 Windows / WSL / SSH 已有账号导入继续保留。新增合成格式、路由、凭据过滤、批量回滚、重试与桌面/窄屏预览回归。

管理器 JSON 每个最多 1 MB、50 个条目。不迁移分组、标签、密码备注、MCP、hooks 或其他执行配置。导入不验证令牌是否有效；不同引擎文件分别选择对应引擎。详见 [账号导入说明](../account-import.md)。
