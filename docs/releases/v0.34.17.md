# Duo v0.34.17

- 修复已有 Harness 任务的权限下拉框被禁用、后端拒绝切换权限的问题。会话输入框支持选择官方“工作区权限（需要提升权限时询问）”或“完全访问（不询问）”，提示同步显示所选权限。
- 所选权限在下次发送时生效，当前执行保持原权限；排队消息及中断后的优先消息各自使用提交时保存的权限。支持从完全访问收回到工作区权限，保留旧任务原有权限语义。
- 权限发生变化时先关闭旧 Harness 进程，再以新权限恢复同一个原生会话，保留历史、模型和执行环境；关闭失败时终止本轮，不沿用旧权限发送消息、不自动重放输入。执行环境、工作目录、程序身份及独立知识整理的工具边界继续受到限制。

完整 Go 测试及 vet、TypeScript 检查、39 项网页回归和 128 个桌面/手机界面用例通过，并人工复查权限选择及运行中场景截图。回归使用合成 ACP 进程及内存网页，覆盖双向权限切换、原生历史恢复、繁忙任务、关闭失败、队列和中断消息权限隔离；不调用真实模型，不改变用户任务、账号或环境配置。
