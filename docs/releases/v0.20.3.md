# Duo v0.20.3

## 脱敏工作区迁移

- 在“设置 → 数据与存储”新增脱敏工作区 ZIP 导出/导入。
- 包含任务、对话、执行记录、知识、待办和备注；导入始终追加为新任务，不覆盖现有数据。
- 导入的任务会重新绑定当前电脑的默认执行环境和工作目录，会话状态重置为空闲。
- 明确排除密码、登录会话、飞书连接、Codex/Claude/Harness/API 凭据、SSH 私钥、硬件配置、机器路径和附件原文。
- ZIP 会在写入数据库前完成格式、大小、路径和内容校验；异常时整批回滚。

## 数据目录切换

原有“切换完整数据目录”仍保留在“高级”区域，仅适合同一台电脑的本地恢复；跨电脑迁移请使用上面的脱敏工作区包。

## 发布文件

- `Duo-Setup-User-x64.exe`：Windows 安装、升级、修复通用。
- `Duo-portable-windows-x64.zip`：免安装便携版，数据保存在程序旁的 `data` 目录。
- 两个包都附带 SHA-256 校验文件。
