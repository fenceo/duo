# Duo v0.34.18

- 环境列表的 Claude Code 和 MiMo Code 行增加“配置 API”入口，自动选中目标环境和工具。Claude 支持 Anthropic 官方 API、MiMo 按量/Token Plan 预设及第三方 Messages 兼容地址；可选择 API Key 或 Bearer Token 请求头。MiMo 支持官方和自定义 OpenAI Chat / Anthropic Messages 兼容 API。
- API 表单提供“验证认证并读取模型”，仅从所选环境发起模型目录 GET 请求，不发送推理请求、不保存或回显密钥。明确区分认证通过、模型列表不支持和模型调用尚未验证；地址、协议、认证方式或环境改变时丢弃过期结果。
- Claude 第三方配置固定默认模型、Opus/Sonnet/Haiku 及子任务模型映射；切换账号时同步路由字段，保留目标的工具权限、MCP 和其他设置。MiMo API 使用独立原生配置文件，激活后由 Duo 在该环境调用时引用；保留 MiMo 原有会话数据目录。
- 接入官方 MiMo Code 原生 ACP：创建与恢复持久化会话、流式输出、模型切换、Build/Plan 和原生 allow 权限、单次工具审批、停止与中断后发送。恢复失败保留原会话标识，不自动新建空白会话或重放输入；无法确认进程结束时保留独占占用。
- MiMo 一键安装/更新使用小米当前官方独立二进制发行，Windows x64 使用 baseline 包，WSL/SSH 使用对应 Linux 包；独立目录安装、验证版本后才保存路径，不使用旧 `@xiaomi-mimo/cli` alpha 包。设置中支持自定义 CLI 路径、默认模型和模型目录，Windows 不依赖 Unix `env` 命令。

MiMo 权限遵循原生代理和工具规则，不提供操作系统沙箱或禁用联网保证。独立知识整理、无工具推理测试和 Duo 桌面/硬件工具暂未开放；API 认证/模型目录验证不等同于实际模型调用通过。

使用说明见 [Claude Code 与 MiMo 配置](../claude-mimo.md)。

验证：Go 全量测试及 vet、TypeScript 检查和构建、40 项网页回归、133 个桌面及窄屏界面用例通过。官方 MiMo Code 0.1.15 的独立空白环境验收通过模型目录读取、ACP 握手、会话创建/恢复、模型选择、Plan 切换和进程退出检查，未发送推理请求、读取用户凭据或消耗模型额度。WSL/SSH 安装链路使用合成测试与源码检查，尚未在真实远程环境执行安装。
