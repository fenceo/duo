# v0.34.64

- 知识体系明确分成两层：工作区任务原件和笔记目录中的平台共识、系统知识、项目知识。任务主 Markdown 在每轮结束维护当前目标、验收、计划、进展、决策、证据和下一步，按时间保留变化与来源；无有效结构化结果时不编造状态。
- 人工修改自动状态区后暂停自动替换，区域外正文保持原字节。切换引擎沿用现有有限交接与同工作区任务引用，不要求重放全部对话。
- 新笔记配置直接使用选定根目录，默认中文分类与标题文件名，生成分类和项目/主题首页；旧版额外 Duo 子目录与旧导出设置保持兼容，不自动迁移或删除旧文件。
- 自动、一键和定时整理共享已有结构化候选提取，不额外请求模型。定时可设 1～168 小时，Duo 运行时执行；没有候选的旧对话仍需显式 AI 整理。
- 同层级、同范围、同标题的新内容进入待合并修订，保留旧正文；支持预览、采用或忽略。采用后退回待核对状态，保留来源历史；并发编辑和跨设备修订冲突不会静默覆盖。
- 每轮可按当前问题检索少量相关项目/系统知识，携带依据、适用条件与待验证提示。当前使用关键词匹配，不是向量检索或 GraphRAG；平台共识仍需明确确认后进入既有恢复流程。
- 提供离线旧知识整理脚本：默认预览，只能写入新目录，同项目/主题重复正文合并并保留原文件路径与哈希；无依据内容保留待整理笔记，疑似凭据只保留来源引用，前后校验原件不变。输出是重建条目及来源身份后的独立阅读整理视图，不是正式数据库迁移。

实现边界和使用方法见 `docs/knowledge-layers.md` 与 `docs/knowledge-rebuild-architecture.md`。当前任务状态在每轮结束更新，尚无逐工具事件实时检查点；定时整理不自动对任意旧聊天进行语义重写。数据库仍保存正文快照与索引，Markdown 外部编辑采用冲突检测。

发布不自动安装、重启本机 Duo，也不自动切换用户笔记根目录。本轮不调用真实模型验证整理质量。

本地整理目录尚未同步入现有 Duo 数据库。已有数据库直接切到该目录可能重复导入，不能视为无重复迁移。正式迁移后续需保留原条目身份、来源及修订历史，实现既有路径接管和迁移冲突预览，并完成小批验证后再切换正式配置。
