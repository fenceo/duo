# v0.34.10

补齐个人工作台在不同执行环境中的账号配置流程。

- 账号管理新增账号可选择 Windows、WSL 或 SSH。Codex 在目标用户下进行 ChatGPT 设备码登录或 API Key 配置，不再要求先在 Windows 登录再同步。
- Claude API 配置同样支持所选 WSL/SSH 环境；订阅登录仍引用已有配置目录。
- 新增账号仅保存独立库存，点击账号卡片的“切换到环境”后应用；纠正“设为新任务默认/切换 AI”的旧提示。不会修改任务、会话或排队消息。
- 目标登录进程清除继承的 API Key 和地址，使用独立 CODEX_HOME；取消时按目标进程标识清理。创建目录不覆盖已有文件，目标连接在配置期间变化时不保存错误环境引用。
- 引擎目录明确 GPT 是模型、Codex 是 CLI 引擎。Harness 提供 API 配置与模型发现，更新已支持单次审批的能力说明，不提供订阅账号登录。

WSL/SSH 新增账号需要目标用户具有 Python 3 和主目录写入权限。已有账号、任务和配置不迁移。Harness API 验证与模型发现沿用 v0.34.8，权限沿用 v0.34.9。

回归使用合成账号和隔离目录；WSL 登录协议与取消使用模拟 Codex RPC，不进行真实账号登录或付费模型调用。
