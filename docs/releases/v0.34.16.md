# Duo v0.34.16

- 左侧会话三个点菜单增加“在 VS Code 中打开”，文件面板支持打开任务项目、文件及指定行号。对话中的常见代码文件引用和 Markdown 文件链接可点击定位，代码块不自动转换。
- 使用当前访问设备的 VS Code：Windows 打开本机目录，WSL 通过 WSL 扩展连接同名发行版，SSH 通过 Remote - SSH 及本机 Host 别名连接远端。连接预览显示目标、匹配确认、SSH 配置示例和可复制打开命令；不在服务电脑后台启动编辑器，不复制代码或凭据、不改变默认用户及 SSH 配置。
- 文件引用限制在任务工作目录内，复用现有读取接口验证文件边界；连接中的特殊字符按 URI 编码，关闭弹窗或重新登录后丢弃过期响应。浏览器请求打开不冒充编辑器已成功连接。
- Windows UNC 路径暂不支持；WSL 指定用户须与发行版默认用户一致，SSH 别名须匹配任务的主机、用户和端口。远程扩展仍需满足自身的连接和运行依赖。本版未引入 VS Code 插件或新的 AI 会话。

使用说明见 [VS Code 联动](../vscode.md)。完整 Go 测试及 vet、TypeScript 检查、39 项网页回归及 124 个桌面/手机尺寸用例通过；已人工复查连接预览和文件面板截图，并通过本机 VS Code 官方 CLI 试开项目及文件/行号参数。WSL/SSH 仅验证合成连接目标和编码，不连接真实 SSH、不改变 WSL、账号或密钥配置，不调用模型。
