# v0.34.2

- Codex 原生会话被另一执行器占用时，明确提示结束占用它的 Codex 桌面版或终端会话后重试，并行工作需使用独立会话。保留原生会话 ID，不自动清空、重发或强杀其他应用。
- 修复进程清理错误覆盖原始执行失败原因的问题。会话占用等原始失败保留为主要错误，清理异常作为附加信息。
- Windows 进程退出与清理并发时，仅在 `cmd.Wait` 已确认主进程退出后纠正误导的主进程终止提示；子进程停止未确认时仍如实报告，不把访问拒绝当成退出成功。
- 新增合成原生协议回归，覆盖会话占用、禁止自动开启新会话、禁止占用后执行，以及已确认和未确认退出的错误保留。没有终止用户的 Codex 桌面会话，也没有调用真实模型。
