# v0.34.13

DeepSeek Harness 接通 Duo 桌面与硬件工具，并支持为 API 模型配置图片输入能力。

- 使用官方 ACP HTTP MCP 声明挂载当前任务已授权的工具。默认不增加授权；桌面查看/操作、设备读取/写入/电源仍按 Duo 现有授权边界执行。
- 工具连接使用每轮独立凭据。结束或取消后关闭 Harness 工具进程，下一轮恢复同一个原生会话并使用新凭据；保留历史，不重发上一轮提示词。撤销授权立即生效，新增授权从下一轮生效。
- 在 Windows 本机或所选 WSL/SSH 执行环境中验证 Duo 工具地址；WSL 支持现有访问地址回退。连接或官方 HTTP MCP 能力检查失败时，在发送提示词之前停止，不静默忽略工具授权。
- 环境的“配置 API”增加“所选模型输入能力”：原生默认/保留已有设置、仅文字、文字和图片。声明写入官方模型 `input` 配置，只修改所选模型；刷新模型列表保留同一端点的其他模型元数据，更换端点清除旧声明。
- 读取模型列表不推断视觉能力，也不发推理请求；声明图片支持不代表服务商和模型已通过图片可用性测试。旧客户端未提供输入能力时继续保留原生配置。

回归覆盖每轮凭据更新、原生历史恢复、取消后续聊、授权撤销、工具预检失败、旧版 MCP 能力拒绝，以及模型能力配置和网页异步隔离。官方已安装 WSL Harness 使用独立临时配置与回环模拟模型/MCP 验证，不访问付费 API、不操作真实桌面或设备。

普通问题弹窗、独立知识总结、输出图片展示及计费用量统计仍待后续接入；本版本不宣称与官方桌面端全部功能一致。
