# Duo v0.34.70

## 便签置顶与单条配色

- 每条便签新增“置顶／取消置顶”和颜色选择。置顶项优先显示，同组保留原有顺序；取消置顶后按原顺序回到普通便签。
- 颜色仅改变当前便签，不再改变整个便签板。支持默认、奶黄、浅蓝、浅绿、淡紫及浅／深色界面；新便签使用默认色。
- 已有便签继承原便签板颜色；保存、刷新、导出／导入保留各自颜色和置顶状态。输入、输入法组合、保存中的草稿、多窗口冲突及撤销删除保护继续有效。

## 知识空白与重复检查

- 打开“知识库 → 目录与整理 → 检查知识空白与重复”，手动检查已导入的三类正式知识，可从结果打开原文并使用现有编辑器修订。
- 检查仅有标题／注释而缺少正文的条目，以及同分类、同主题／项目范围内正文相同的候选。简短有效知识、代码和链接不按字数判为空白。
- 检查为只读，不调用模型、不自动删除或合并。不会扫描未同步文件、历史归档或逐轮记录；正文相同也可能有不同依据和适用条件，需阅读核对。
- 扫描最多 2,000 条或 32 MiB，结果有界，达到上限明确提示。本功能不代表已完成本机笔记清理或语义去重。

## 上下文占用与 AHA2 参考审查

- 原生 Codex app-server 提供有效最新输入 token 和模型上下文窗口时，显示当前请求上下文占用；与累计计费用量分开，压缩后占用可以下降。缺少真实窗口时不猜测容量。
- 新增 [AHA2 源码审查与采用计划](../aha2-review-20261103.md)，基于 `3698996a` 对照知识维护、上下文、MCP、任务／渠道权限、工作区、硬件、桌面和同步边界，注明已采用、后续方向与不宜照搬项。

本轮不升级正在运行的服务、不重写用户笔记、不调用真实模型。使用合成资料与模拟 JSON-RPC 子进程验证；AHA2 仅做静态审查，未安装运行。
