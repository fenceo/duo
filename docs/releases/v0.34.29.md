- 文档补充 Z.ai / GLM 的地址、认证方式、模型 ID 来源与目录读取的三种结果，并说明该预设与 Anthropic 官方预设、MiMo 预设的区别。

验证：Go 全量测试与 vet、TypeScript 检查与构建、43 项网页回归通过。新增合成回归覆盖 Z.ai 预设的地址/认证头/协议/角色模式与已保存配置回显，以及 200 错误对象（数值与字符串错误码）被判定为失败且 Key 不出现在任何返回字段中；全部使用合成 fixture，不发送推理请求、不读取真实凭据。
