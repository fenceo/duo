# v0.13.0

布局从「固定两栏」变成可以自己摆的三栏：便签栏和工具面板都能换位置。

- 便签栏可以放在任务栏、左栏、右栏或对话下方；工具面板可以放左栏或右栏。
- 拖动面板标题左侧的 ⠿ 手柄换栏，拖动时目标栏会显示虚线占位；双击手柄按顺序切换，回车键同理。
- 界面设置里新增「面板位置」，两个下拉框可以直接指定便签栏和工具面板的位置。
- 左栏、右栏的宽度都能用鼠标拖动调整，双击把手恢复默认；滑杆文案改为「左右工具栏宽度」。
- 窄于 760 像素的窗口自动回到单栏，便签栏挪到对话下方。
- 位置和宽度都存在当前浏览器里，同一台电脑的另一个浏览器不受影响。

## 下载

下载 `Jianzuo-portable-windows-x64.zip` 后完整解压，双击 `简作.exe`。`Jianzuo-portable-windows-x64.zip.sha256` 用于校验下载完整性。

已有用户：先退出程序并备份 data，替换程序文件时保留 data。布局保存在浏览器本地，升级不需要迁移。
