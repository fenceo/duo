# v0.15.0

知识按任务沉淀，便签改成能勾的待办。两件事都跟着任务走，不再散落在日期里。

## 新增：任务知识

每个任务有自己的知识库，一条知识包含标题、正文、状态和来源。

- 状态分「已验证」「待验证」「过时」三档，来源分「任务」「飞书」「整理」「迁移」「手动」，一眼能看出这条是怎么来的。
- 每轮对话结束后，用量那行的右侧多一个「沉淀为知识」按钮，点一下就把这轮结论存进当前任务；已经存过的那轮按钮变成「已沉淀」并置灰，不会重复存。
- 知识面板支持编辑、删除、切换状态，也能把某一条直接放进输入框继续追问。
- 面板顶部可按状态筛选，并提供 Markdown 导出，方便贴到文档或提交记录里。
- 飞书卡片上的「保存知识」写入同一份知识库，全局搜索也能搜到知识条目。
- 以前那个整块的任务便签会在升级时一次性迁移成一条「任务知识」，内容不丢。

## 改进：便签变成待办

侧栏那块常开的板块现在叫「待办」，每张卡片是勾选框加标题，可以记截止日期和颜色。

- 状态分「待办」「进行中」「已完成」，勾选即时变成已完成；逾期未完成的日期标红。
- 侧栏可切换「未完成 / 全部 / 已完成」，范围可选「本任务 / 全部任务」，标题旁显示还有几项没做完。
- 任务页里的「待办」标签用的是同一份数据，两边改动立刻同步。
- 备注里的命令或线索可以一键放进当前输入框，接着让 AI 处理。

## 新增接口

- `GET|POST /api/tasks/{id}/knowledge`、`PUT|DELETE /api/tasks/{id}/knowledge/{kid}`：任务知识的读写。
- `POST /api/tasks/{id}/knowledge/from-run`：把某一轮执行结果存成知识。
- 知识列表加 `?download=1` 可直接导出 Markdown。
- 待办沿用 `/api/tasks/{id}/scratch`，数据结构增加 `title`、`status`、`due`、`done_at`。

## 从 0.12.0 直接升级的用户

中间的 0.13.0 和 0.14.x 也一并包含在这个版本里：三栏布局可以自由摆放、栏宽可用鼠标拖动，模型选择改成点开就能挑和搜索、能读第三方模型目录，以及换模型后答非所问时的会话来源提示和「新建会话」。

## 下载

下载 `Jianzuo-portable-windows-x64.zip` 后完整解压，双击 `简作.exe`。`Jianzuo-portable-windows-x64.zip.sha256` 用于校验下载完整性。

已有用户：先退出程序并备份 data，替换程序文件时保留 data。这次会新增 `knowledge_entries` 表并把旧的任务便签迁移进去，迁移只执行一次，原内容保留。
