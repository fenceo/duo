# v0.17.0

新增无需管理员权限的 Windows 当前用户安装器，同时保留便携版和自动更新。

## 新增：Windows 用户级安装器

- 新增 `Jianzuo-Setup-User-x64.exe`，默认安装到 `%LOCALAPPDATA%\Programs\Jianzuo`，数据保存在 `%LOCALAPPDATA%\Jianzuo\data`。
- 安装只作用于当前用户，不请求 UAC；可创建开始菜单和可选桌面快捷方式。
- 自启动使用当前用户的 `Jianzuo User` 计划任务，登录后以普通权限启动，不安装系统服务。
- 安装器会清理旧版便携启动的 `HKCU\...\Run\JianzuoPortable`，并在升级或更换目录时替换旧的简作计划任务。
- 卸载会删除程序、快捷方式和计划任务，但保留数据目录。重新安装时会沿用已有数据目录。

## 修复

- 安装器拒绝磁盘或文件系统根目录，避免升级和卸载时错误递归删除。
- 修正 Windows 命令行参数引用，路径末尾反斜杠不会再破坏快捷方式、计划任务或卸载命令。
- 安装器内嵌同一版本的便携包，构建时自动校验 EXE、PE 头和发布包完整性。

## 下载

- 推荐：`Jianzuo-Setup-User-x64.exe`，双击按向导安装。
- 便携：`Jianzuo-portable-windows-x64.zip`，完整解压后双击 `简作.exe`。
- 两种方式都提供 `.sha256` 校验文件，自动更新继续使用便携 ZIP。
