# Duo v0.24.3

- 修复新版 Codex 异步提问只显示文字、没有可选答案的问题。读取 `agentMessage.delivery=async` 与 `questions`，保留选项和自由填写字段。
- 待回答问题独立保存，不受最终回复、中间过程开关或最近 5 轮分页影响；刷新和服务重启后仍可回答。切换原生会话后不再显示旧会话的问题。
- 提交答案会作为下一条消息排队发送到原任务，界面明确提示排队方式；支持暂不回答。答案入队和问题完成状态在同一事务中保存，网络重试不重复发送。
- 保留原生同步问题、命令及权限审批流程；异步问题不会冒充最终回复或审批请求。
- 发布工作流改为从 main 编译发布，界面验收不再创建截图分支。
- 新增原生协议、持久化、会话隔离、重复提交和网页选项回归，使用合成数据，不调用真实模型。
