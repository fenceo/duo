# Duo v0.21.0

新建任务或切换任务后，可以搜索并引用之前的任务记录、经验结论及 Obsidian 笔记。引用保留来源、可信状态和版本，先放入输入框供检查，不会自动调用模型。

- 新增跨任务知识库入口，支持关键词、任务与资料类型筛选，默认排除过时结论。
- 支持将知识保存为 Obsidian Vault 中的普通 Markdown；可选择同时导出已结束任务的原始问题、回复及错误。
- 每分钟同步本地文档，支持手动重建索引。在另一台电脑用 Git 拉取 Vault 后即可查询引用，无需复制 Duo 数据库或账号配置。
- 支持 Obsidian 对已有结论的编辑回传；保留自定义属性，两端同时修改时提示冲突并保留内容。
- 文件删除不自动重建；合并冲突、无效 YAML、过大文件及链接目录会明确提示。不会自动 Git 提交或推送。
- 修复任务知识导出超过 500 条时遗漏、长知识无法整理、“仅已验证知识”混入其他状态、截断标识不准确、编辑草稿后丢失执行来源，以及同执行并发保存产生新重复条目的问题。
- 同时包含此前本地 v0.20.17 的 Harness ACP 会话恢复与空闲时切换模型改进。

使用方式：打开左侧“知识库 · 历史与结论”，展开“Obsidian Vault 与 Git 同步”，选择已有 Vault 目录。详细流程见 [知识库与 Git 指南](../knowledge-vault.md)。

迁移为新增 SQLite 缓存及同步基线表，默认不开启 Vault。不会移动现有任务、凭据或运行环境。Vault 中的 Markdown 可以包含私人项目内容，建议私有仓库，并在提交前检查。真实模型回复不属于离线回归验证范围。
