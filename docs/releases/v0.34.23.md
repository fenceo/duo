# Duo v0.34.23

- 简化 Claude Code API 配置的服务预设：默认 Anthropic 官方 API、自定义 Messages 兼容 API、一个 MiMo 兼容 API 入口。MiMo 套餐/区域在选中对应服务后展开，不再用大量 MiMo 项占据主预设。
- Claude Code 和 MiMo Code 窗口使用各自的默认服务、协议和提示；打开窗口、等待读取及读取失败时立即清空前一个引擎的状态。已保存的 Claude-to-MiMo 配置仍正确回显，不自动改写原生配置。
- 切换服务后清空旧模型和待输入的 Key，明确提示重新填写当前服务的 Key；保留同一服务的已保存 Key 留空复用规则。校验 API 响应的引擎/环境，拒绝错位响应和迟到覆盖。
- Claude API 视图不再附带 MiMo 配置路径；两个引擎的原生配置、权限和历史仍分别保留。本轮不修改用户配置，也不调用真实模型。

验证：Go 全量测试、vet、TypeScript 检查与构建、40 项网页回归及 143 个桌面/窄屏界面用例通过；检查了 Claude 官方、Claude 使用 MiMo 及 MiMo CLI 的独立配置界面。新增回归覆盖主预设收敛、套餐条件展开、等待/失败时状态重置、旧模型/Key 清理、原生配置视图隔离和迟到响应拒绝。
