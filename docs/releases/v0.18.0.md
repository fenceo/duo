# v0.18.0

本版将原生 AI 引擎与工作台流程优化合并为正式发布。

## AI 引擎与任务

- 接入 DeepSeek Harness SDK JSON-RPC，支持执行环境中的 provider、自定义模型 ID、推理强度、同进程连续对话与停止。
- Harness 显示原生会话是否可继续；失效后可新建空白会话，保留任务记录与知识，不自动重放历史。
- 工作台保留 Codex 原生会话、审批与取消能力；不同引擎按实际能力展示权限与功能，不把自动审批等同于无条件放行。
- 修复快速重复提交、切换任务后的异步结果覆盖，以及部分提交/附件上传失败时的草稿丢失；可只重试未上传附件。
- 模型测试只测试当前选中的模型，事先确认额度消耗，并阻止重复测试和过期结果覆盖。

## 界面

- 新建页按执行环境、目录、任务要求、权限和模型分层，统一字号、间距和控件尺寸。
- 修复模型选择器未匹配样式导致的宽度与截断问题，改善长模型 ID 的展示。
- 统一设置与引擎卡片的浅色/深色主题，优化窄屏和手机触控布局。

## 发布与升级

- 每轮优化通过测试后发布正式 Release，同时提供安装版、便携版与各自 SHA-256。
- 发布构建运行全部网页回归，并校验嵌入资源与提交源码一致、服务版本一致，以及打包程序的登录/CSRF和任务接口。
- 升级保留原有数据、任务、知识和执行环境配置。安装版使用安装包；便携版可使用设置中的版本更新。
- 安装器增加安装所有权检查；卸载仅删除自有文件，保留安装目录中的其他文件，快捷方式、注册表和启动项也按安装路径核验归属。

## 能力边界

- Harness 停止、闲置回收或服务重启后不支持跨进程原生恢复；“新建空白会话”不是恢复旧上下文。
- Harness 暂不支持简作的交互审批、附件、自动知识总结和硬件授权；当前真实调用验证以 WSL 为准，Windows 原生 SDK 启动仍有兼容性限制。
- Kimi、MiMo 仍为引擎目录与后续适配规划，不表示已经具备可运行的适配器。
