# Duo v0.22.9

本版本梳理知识库的查找、预览、引用和维护流程，减少长记录堆叠，并修复编辑期间的版本冲突问题。

- 全局知识库默认浏览知识条目；原始对话与独立文件笔记可单独选择，自动记录、手工整理和文件目录可按来源筛选。
- 增加正文预览与来源任务入口。桌面并排浏览，手机在结果和预览之间切换；超长内容显示截断说明。
- 检索展示总数和“加载更多”，可继续浏览超过 60 条的结果。已验证知识优先，过时资料默认排除。
- 显示自动记录、新会话补回和文件同步的实际状态，并说明哪些知识会被 AI 使用。打开浏览器不会覆盖设置页草稿。
- 本任务知识增加关键词和来源筛选，正文按需展开；编辑、引用、验证和设为过时使用明确文字操作。
- 任务内引用也携带来源、验证状态和版本校验，保留现有输入；重复点击、请求失败和任务切换不会插入重复或错误目标的资料。
- 编辑知识时固定打开条目时的版本号，防止后台刷新后用新版本号覆盖旧草稿。冲突时保留编辑内容并提示核对。
- 保持已有数据库、自动积累策略与 Vault 文件同步指纹兼容；不自动删除、合并或验证历史条目，不新增模型调用。

检索仍为本地关键词匹配。自动补回仍仅在新会话启动时选取本任务最多 3 条知识，跨任务和文件资料通过手动引用使用。

新增来源分页、预览脱敏、引用版本与编辑冲突回归，并使用合成数据验收桌面、手机、深浅主题以及文件同步。

发布文件：Windows 安装器、便携 ZIP 及各自的 SHA-256 校验文件。
