# Duo v0.22.7

本版本合并自动知识积累、知识库入口与路径设置、早期参考项目专用代码清理，以及 Windows 自动发布流程。

## 对话自动积累

- 成功完成对话后，默认保存本轮要求摘录和最终回复，保留任务及执行来源，状态为待验证；网页和飞书均适用，不额外调用模型。
- 相同任务内完全相同、未截断的要求与回复去重。失败、中断、空结果与独立知识整理草稿不自动入库；保留人工纠错、验证及删除结果。
- 开启新的原生会话时，可自动补回当前任务最多 3 条知识，优先已验证内容；每条正文最多 1200 字。正常续聊不重复添加，过时条目和其他任务不会自动带入。

## 知识库管理与文件目录

- “更多 → 本任务知识”管理当前任务的知识；全局知识库查询同一批条目，并提供跨任务检索和显式引用。两处增加互相跳转，“手动整理”保留为可选操作。
- “设置 → 知识库”集中管理自动记录、自动恢复、知识文件根目录和同步范围，支持普通文件夹或 Obsidian Vault。
- 设置页分别显示本机运行数据目录与实际 Markdown 文件目录 `<所选根目录>/Duo`。任务、对话和知识仍共用原数据库，完整数据迁移使用“数据与存储”。
- 自动条目的文件导出与完整执行记录导出分别选择，默认均关闭。更换文件目录保留旧文件和本机知识，不自动搬移旧目录中的独立笔记。
- 设置读取失败、过期响应和重复保存有保护，避免覆盖配置或重复同步。

## 项目独立性与发布

- 移除早期参考项目的专用上下文目录检测及测试引用，保留当前 AI 工具所需的通用工作区指令提示。
- 增加 GitHub Actions Windows 发布流程：通过 SSH 推送对应版本发布分支即可运行现有完整测试、打包及发布脚本，无需本机 GitHub CLI 登录或个人令牌。
- 云端发布失败时提供脱敏的检查摘要，并在检查与打包之间复用 Go 缓存。
- 发布保留生成资源一致性、成品版本、HTTP 验收、四个文件大小及正式版 latest 校验，不覆盖已有 Release。

## 升级说明

- 自动积累只作用于升级后完成的对话，不自动回填旧记录，不做语义提炼或事实验证。
- 自动积累保存内容经过常见凭据脱敏并受容量限制。自动恢复会增加本轮模型输入；跨任务知识继续经用户选择后引用。
- 保留已有任务、对话、知识及同步设置，不迁移数据库。关闭积累或同步不会删除已有记录和文件。

发布文件：Windows 安装器 `Duo-Setup-User-x64.exe`、便携包 `Duo-portable-windows-x64.zip`，以及各自的 SHA-256 文件。
