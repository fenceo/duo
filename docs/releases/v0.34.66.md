# Duo v0.34.66

任务记录在长历史、引擎续接和知识整理时保持连续，并能明确区分已记录资料与尚未维护的任务状态。

## 任务记录

- 工作区主 Markdown 保留当前目标、计划、来源状态和人工备注。模型没有提供有效 `task_state` 时，明确显示维护缺口，保留先前状态，不从问候、问题或执行成功推断目标与计划完成。
- 长记录按发生月份分页，主文档保留历史导航和最近进展。已有正文不搬移、不重写；人工修改的受管区继续报告冲突。
- 历史按检查点分批回填，超过旧版 2,000 轮或 32 MiB 总历史的资料可继续同步。较早启动、较晚结束的轮次有单独跟踪，不被新记录越过。写入未完成时不推进检查点。
- 未完成的同步进入持久队列，空闲时有限继续；磁盘失败退避，文件冲突暂停，手动同步可重试。不会为同步额外调用模型。

## 引擎交接

- 新会话读取任务文档的有界摘要；继续同一会话时只补入发生变化的文档范围，内容未变则跳过。
- 仅在模型轮次成功并取得原生会话身份后记录读取进度；失败重试和同时发生的人工修改不会被误记为已接收。
- 仍是有界文本交接；未进行真实模型的多引擎接续质量测试，也不是任意长全文自动重放。

## 知识整理与项目范围

- “用 AI 整理本任务”先显示尚未整理的轮数，每批按时间最多 16 轮，包含失败和停止记录，并附当前任务 Markdown 与相关已有主题的有界摘录。
- 成功保存有效结果后记录本批来源；再次点击继续下一批。失败、缺少明确候选数组、候选无依据或保存未完成时不消费来源。
- 同主题进入待合并修订，保留用户正文和待验证状态。例行自动、一键候选归档、定时整理仍不额外调用模型；付费 AI 整理仍须明确触发和确认。
- 在“任务记录 → 知识项目范围”选择或创建稳定项目。任务改名、换目录、切引擎及分叉不依赖标题猜测项目；历史快照保留原项目归属。
- 脱敏工作区 ZIP 携带项目归属，同名或别名冲突保留本机配置并显示警告，旧 ZIP 仍可导入。
- 检索排除已经注入的知识检索块，避免资料中的项目名再次触发自身召回。系统知识仍可跨项目参考，用户明确提及其他项目时仍可查询。

## 边界与升级

主文档和每个历史页仍限 1 MiB，正常分页目标约 256 KiB；单月最多 9,999 页，最多跟踪 2,000 个尚未结束的历史孔位，异常会保留原文并说明。超过 1 MiB 的人工主文档不会被裁剪或改写，新进展仍可写入历史页。

迟完成或后导入的旧轮次保留原时间，在发现时追加，不重排已有正文。导出检查点不会每轮全量修复用户事后删除的旧正文；重放或重置检查点时才重新回填。

本版不自动升级正在运行的 Duo，不切换现有笔记根，不移动或删除旧笔记。执行中实时 checkpoint、自动付费语义整理、跨主题语义去重/矛盾消解、旧目录保留身份的正式迁移和向量检索仍是后续工作。
