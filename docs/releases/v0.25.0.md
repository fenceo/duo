# Duo v0.25.0

- 设置新增本机 Windows x64 一键安装 Codex、Claude Code 和 DeepSeek Harness。自动准备并校验 Node.js，隔离安装到数据目录，启动检查通过后保存环境路径；不下载本地模型。
- 新增 Codex ChatGPT 设备码登录、API key 和自定义 Responses API 配置。每个账号使用独立原生配置目录，可设为新任务默认，或通过“切换 AI”接续现有任务。
- 新增桌面共享首版：选择整个桌面或前台窗口，默认仅查看；明确授权后，Codex/Claude 可截图、点击、滚动、输入文字或按键。30 分钟临时授权，支持立即停止共享、任务隔离、用户输入变化检测和一次性截图凭据。
- 登录、安装及桌面共享期间禁止自动更新重启，避免中断正在进行的操作；新功能回归使用合成账号、临时目录和独立 CI 窗口。
- 包含 v0.24.3 的异步选项卡修复，发布统一从 main 执行，不创建临时远端分支。

目前自动安装和新增账号界面以 Windows/Codex 为首批支持；Claude/Harness API 配置沿用原生工具和配置目录引用。桌面控制影响真实桌面，不是后台隔离，管理员和安全桌面可能拒绝操作。更多说明见 docs/engine-onboarding.md 与 docs/desktop-sharing.md。
