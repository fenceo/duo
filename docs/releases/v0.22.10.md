# Duo v0.22.10

修复长任务中输入迟缓、周期性卡顿和大量工具记录拖慢页面的问题。

- 输入文字只更新草稿和发送按钮，移除每次输入触发的两次工作流刷新，避免重复更新附件、工作模式与审批表单。
- 空闲轮询不再遍历并改写全部历史记录，也不读取历史区布局；有变化时只更新受影响的轮次。
- 折叠的执行记录不挂载正文节点。展开一轮时先显示最近 100 条，可分批加载更早记录；工具输出正文在展开该工具时才渲染。
- 保持完整历史与搜索定位，搜索可直接展开尚未显示的命中记录。最终回复、错误、附件、知识记录状态及执行用量继续显示。
- 覆盖没有新增事件时的运行完成、最终回复重新归类、草稿与输入法、发送锁定、记录翻页、工具正文、搜索及切换任务。

4,800 条、约 571 万字符的合成任务在同一浏览器测试中，默认历史区节点由 19,464 个降至 456 个，首次挂载由约 719 ms 降至 35 ms；包含任务状态刷新的空闲轮询由平均 15.8 ms 降至 1.65 ms。测量受电脑与浏览器负载影响，不代表所有设备的固定耗时。

此次调整仅改变页面显示和刷新方式，不删除或压缩任务记录，不改变模型会话与硬件权限，不新增模型调用。更新后重新加载页面即可使用；尚未发送的草稿请先自行保留。

发布文件：Windows 安装器、便携 ZIP 及各自的 SHA-256 校验文件。
