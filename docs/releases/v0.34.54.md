# v0.34.54

改进任务启动失败诊断，便于区分执行环境错误、ACP 初始化失败与模型请求失败。

- 传入历史记录或附件失败时，同时保留 stdout 和 stderr，并解码 WSL 的 UTF-16 错误；WSL 服务拒绝访问不再只显示空白的 exit status。
- 区分附件暂存命令超时与用户取消，并保留底层错误类型。
- Harness ACP 握手失败显示实际生效的等待上限；子进程已经退出时保留启动失败信息，避免误报为仍在等待。
- 补充合成回归，覆盖双流/UTF-16 错误、取消/超时及 ACP 子进程退出。没有改变任务的执行用户、账号目录或超时设置。

本版改善诊断，不会自动修复 Windows/WSL 服务权限或外部 CLI 的启动环境，也不会清空或重建原生会话。普通 Windows 用户上下文的全量 Go 回归、网页回归、类型检查、构建及 go vet 通过。无提示词的 Windows Harness initialize/close 检查通过；未发送真实模型请求。
