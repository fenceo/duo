# v0.34.30

- MiMo Code 任务获得设备授权后，Duo 会在原生 `session/new`（恢复会话时同样）声明本轮的 Duo 桌面/硬件工具地址和凭据，凭据只对应当前一轮，收回授权立即失效。此前 MiMo 会在存在硬件授权时直接拒绝执行整轮任务，必须先收回授权。
- MiMo 的硬件接入改为能力驱动：`initialize` 未声明 HTTP MCP 能力时明确拒绝本次执行并提示升级 CLI 或先收回授权，不会在缺少工具的情况下静默运行，也不会把凭据写进启动参数、环境变量或原生配置。是否声明由该环境的 MiMo Code 版本决定。
- 文档同步更新 MiMo 的硬件工具说明、引擎对照表与相关段落，去掉“尚未接入”的过时表述；独立知识整理与无工具推理测试仍未开放。

验证：Go 全量测试与 vet、TypeScript 检查与构建、网页回归通过。新增合成 ACP 回归覆盖：有授权时 `session/new` 收到本轮 HTTP MCP 声明（类型/名称/地址/`Authorization: Bearer` 凭据逐项校验）、CLI 未声明 HTTP MCP 时失败关闭且不产生回复、无授权时不声明任何工具服务器；全部使用合成 fixture，不发送模型请求、不读取真实设备凭据。真实 MiMo Code 是否声明该能力仍待该环境安装对应版本后确认。
