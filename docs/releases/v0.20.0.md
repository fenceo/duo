# Duo v0.20.0

**[下载 Windows 安装包（新装／升级通用）](https://github.com/fenceo/duo/releases/download/v0.20.0/Duo-Setup-User-x64.exe)**

## 模型选择与界面

- 打开模型选择器即读取当前执行环境、AI 引擎及账号配置的模型列表；Codex 优先使用原生 app-server `model/list`，不再必须先存在模型缓存文件。
- 原生模型目录读取失败时明确说明降级来源。已配置/缓存模型不冒充已验证可调用；打开列表不会发送任务或付费测试消息。
- Claude Code 读取目标环境明确配置的模型；Harness 当前仅列出 Duo 中配置的模型，SDK 没有完整模型目录接口，不再用内置示例冒充可用列表。
- 模型刷新、状态及来源诊断收进模型面板，新建任务的“测试当前模型”仍需明确确认，保留自定义模型 ID 入口。
- 切换环境、引擎、账号或目录后，过期响应不覆盖新选择；不为模型发现偷偷换到另一 WSL 用户。
- 整理左下角：待办与设置工具分区，空待办默认收起，非空待办和错误仍可见；兼顾桌面和手机。

## 安装与数据

- 保留原数据仍是升级默认；交互安装新增“全新配置”与“载入已有数据”，无需先卸载，也不删除原数据。
- 全新配置使用空目录，首次启动后设置密码和环境；载入已有数据使用原密码与配置，不复制或合并任务。
- 已安装程序目录锁定，数据模式和确认提前说明，避免最后一步才提示不支持的目录组合。自动更新不能更换数据目录。
- 载入前只读校验配置和数据库，拒绝活动、损坏、未完成初始化或仍有未落盘 WAL 的数据；不运行数据库迁移来做验证。

## 使用提醒

- 本次升级默认保留数据。需要换数据时先结束任务、关闭终端/硬件并从托盘退出，再重新运行同版本或新版安装包。
- 数据切换不会重装 WSL 或更换 AI CLI 的原生登录；两套数据不会自动合并。请完整保留原数据，不能删除 WAL/日志绕过校验。
- 模型目录是否包含某项与实际账号权限、模型额度不同；真实可用性仍以经过确认的调用测试为准。
- 已在本机 WSL 的现有 Codex 中完成无对话的原生模型目录验证，并用隔离数据验收桌面/手机页面与安装生命周期；没有进行新的付费模型调用。
- Harness 会话恢复、Windows 原生 Harness 和 SSH/硬件真机验证等既有能力边界保持不变，不因本次界面整理而宣称全部支持。
