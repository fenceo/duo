# v0.28.0

- 将执行环境、AI 引擎和引擎安装合并为「环境与引擎」。进入后检测已保存的 Windows、WSL、SSH，分别列出各引擎的安装及登录状态。
- 未安装的 Codex、Claude Code、DeepSeek Harness 可从对应环境直接一键安装。连接失败显示未完成检测；旧环境的迟到检测结果不会覆盖新配置。
- 保留环境连接、工作目录、程序位置和模型目录设置，收纳到统一页面中的环境管理区域。
- 独立账号管理新增 JSON 文件导入和已有环境账号导入。支持 Codex auth.json（可配套 config.toml）以及 Claude 的订阅凭据或 API settings.json。
- 导入为独立账号副本，不覆盖来源文件、不自动切换默认账号；只保留登录与路由字段，不复制 MCP、hooks 或密钥助手。重复提交不会重复创建或覆盖账号。
- 增加合成账号、环境状态隔离及桌面/窄屏导入页面回归。
- 修正异步提问的答案投递：执行中立即引导当前轮次，空闲时继续新一轮；原生确认后才记为已回答，重复提交和接收状态不明时不会再自动排队。

更新后刷新页面。导入不验证令牌有效期，暂不支持第三方管理器批量导出或钥匙串专用凭据。安装仍只安装 CLI，不下载本地模型。详见 [账号导入说明](../account-import.md)。
