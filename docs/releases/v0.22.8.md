# Duo v0.22.8

本版本收紧对话页布局，让聊天记录获得更多可见空间，并把常用知识操作放到直接可见的位置。

- 顶部标题、执行环境和工作目录合并为一行；长内容截断显示，完整路径可在会话菜单查看。
- “本任务知识”直接放在硬件、文件、终端旁边，替换原来的“更多”入口。
- 新建会话、切换工具继续、复制链接、飞书连接及本任务待办集中到右上角“会话”菜单。
- 正常会话的信息说明收进菜单；会话失效时仍显示恢复提示和“新建会话”操作，运行中不能重置会话。
- 输入框顶部不再单独显示引用按钮；“引用”与附件、指令放在底部，桌面空间充足时与模型、发送按钮共用一行，窄屏自动换行。
- 新建任务页的“引用历史 / 知识”也移到输入区底部。空闲时收起重复的状态行，执行、审批、失败和归档状态继续显示。
- 保留会话重置前确认、任务记录、知识及未发送草稿；不改变权限、自动记录或模型调用策略。
- 增加合成页面的桌面、手机、浅色和深色布局验收，以及菜单节点稳定性、直接知识入口和引用位置回归。

发布文件：Windows 安装器、便携 ZIP 及各自的 SHA-256 校验文件。
