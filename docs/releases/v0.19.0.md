# Duo v0.19.0

**[下载 Windows 安装版（新装／升级通用）](https://github.com/fenceo/duo/releases/download/v0.19.0/Duo-Setup-User-x64.exe)**

项目由“简作 / Jianzuo”更名为 **Duo**。界面、安装向导、快捷方式、运行程序及发布包统一使用新名称。已有任务、配置和数据目录保留。

日常使用推荐安装版。便携 ZIP 是可选的免安装形式；两个 SHA-256 文件用于校验，Source code 是开发源码，不是运行程序。

**旧版用户首次转入 Duo 请手动运行上方 EXE。** 文件名已更换，旧更新器不能自动完成品牌迁移；转入 Duo 后可继续应用内升级。

## 统一安装与维护

- 改为 Inno Setup 当前用户中文安装向导，原生管理程序文件、快捷方式、安装信息和卸载。同一个 EXE 用于新装、同目录升级和修复，无需先卸载或单独下载升级包。
- 沿用已有数据目录，不重置任务、知识库、密码、环境或模型凭据；卸载默认保留数据及未知文件。此版本没有数据库格式升级。
- 识别可确认归属的旧便携自启动入口，显示原程序和数据路径，明确确认后迁移入口，备份原任务定义，保留旧程序和原数据。未知入口仍拒绝覆盖；静默升级不能跨目录迁移。
- 修复托盘自启动 COM 索引读取，并兼容旧版重复写入可执行文件路径的启动参数，不再误覆盖其他目录入口。

## 应用内更新

- 显示安装方式，安装版选择完整 EXE，便携版选择 ZIP；坏安装标记不再当成便携版覆盖。安装版应用内升级走与手动安装一致的维护流程。
- 有 AI 任务/队列、模型测试、终端或硬件连接时拒绝更新，不强制停止工作；准备维护后阻止新工作进入，准备失败可以重试。
- 显示检查、下载校验、安装重连、确认新版等实际阶段，防止重复操作。网页仅在健康检查返回目标版本后刷新，超时会显示未确认并允许重新连接。
- 正常显示的版本号不再用 `-portable` 判断安装方式；底层健康接口保留既有协议字段，并单独返回实际版本。

## 工作流与代码边界

- 模型目录与运行任务采用同一个引擎账号引用，修复切换账号后仍读取另一账号模型列表的问题。
- 删除非当前账号配置不再清空当前账号；账号编辑和切换串行处理。
- 登录页面与工作台拥有明确的生命周期：重建页面清理旧监听，迟到请求不覆盖新页面或踢掉新登录，设置页不重复加载。
- 手机端将空待办栏收起、压缩输入工具区，保留筛选和模型入口，为对话正文腾出更多空间；非空待办及会话警告仍完整显示。
- 安装维护收敛到安装器和托盘入口，停用可能强行覆盖他处启动项的旧开发脚本。
- 修复 Windows 终端将系统句柄保留为 Go 指针的用法；保留原有终端行为。
- 补充实际模块边界和未完成能力说明，不重写工作台、不迁移原生引擎凭据。

## 升级提示与边界

- 从旧安装器或便携版转入新的原生安装体系，建议直接下载上方 EXE。先结束任务、断开终端和硬件，再从托盘退出；安装器不会强杀正在运行的Duo。
- 迁移会继续使用原 `data`，不会搬走数据库。原目录内的 `data` 仍在使用时，不能把旧便携目录整体删除。
- 工作台升级不等于升级 WSL、AI CLI 或迁移各引擎登录会话。重要数据请退出服务后完整备份。
- Codex / Claude 历史会话的账号绑定仍有边界：换账号建议新建任务，旧会话续接前切回原账号；本轮没有猜测历史账号或隐式迁移会话。
- 更新日志为数据目录中的 `update.log`；安装版自动升级另有 `update-installer.log`。失败时保留日志及数据，用同一 EXE 修复；数据库兼容性不能靠仅恢复旧程序保证，不承诺任意跨版本数据回退。
