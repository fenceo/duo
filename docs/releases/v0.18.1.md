# v0.18.1

本版修复 Windows 安装器读取已有启动任务时的异常，并完善安装诊断。

## 安装修复

- 修复 Windows 任务计划动作集合的读取方式：`Item` 是带索引的 COM 属性，不是方法。原实现遇到已有启动任务时可能出现“调用的目标发生了异常”，并影响已有数据目录的识别。
- 修正安装前检查、启动任务归属核验和数据目录识别中的三处调用，保留不同安装之间的所有权保护。
- 图形安装失败也会写入诊断日志，错误窗口显示失败步骤、最内层原因、错误码和日志位置，不再只显示外层反射异常。
- 增加真实 Windows COM 回归，覆盖启动任务构造、动作读取、任务识别及仅校验、不注册的任务定义验证；补充临时快捷方式与多层异常测试。

## 安装与数据

- 已安装用户可直接运行新版安装器，沿用原程序和数据目录，无需删除数据或先卸载。
- 如仍然失败，请保留错误窗口截图及 `%LOCALAPPDATA%\Jianzuo\installer-error.log`；日志写入失败时会尝试 `%TEMP%\Jianzuo\installer-error.log`。
- 此版不修改任务、知识库、凭据或执行环境的数据格式。
