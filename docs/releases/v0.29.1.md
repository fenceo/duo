# v0.29.1

- 账号管理升级为总览：引擎分类、账号卡片/列表、搜索、环境和默认状态筛选、排序及隐藏名称。保留本地账号与 Cockpit Tools JSON 导入。
- 账号卡片提供设为新任务默认、当前任务使用、同步到环境、重命名和移除引用。当前任务使用会预选账号并打开切换预览，确认后生效；移除引用保留原生账号文件和已有任务。
- 合并「环境与引擎」中的两套检测入口：一次检测列出已保存 Windows、WSL、SSH 环境的引擎状态，以及本机新发现的 Windows/WSL 环境。已有环境按配置的用户和程序路径检查，同一个 WSL 发行版不再重复探测默认用户。
- 新发现环境先加入待保存配置，确认连接与工作目录后保存；未安装的受支持 CLI 继续提供一键安装。检测失败显示未完成，不当作未安装。

账号总览展示 Duo 已保存的配置与默认状态；本版未增加订阅额度、有效期或在线登录状态查询。不会因打开账号列表而调用模型或切换原生登录。
