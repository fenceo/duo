# Duo v0.34.14

- Harness 可在“本任务知识”中整理知识草稿：使用独立原生会话，提供已有知识与最近最多 8 轮已完成对话的文本摘录，长文本明确标注截断。原聊天会话、权限、附件和桌面/硬件授权不被带入或替换。
- 独立整理通过官方工具扩展拒绝全部工具操作，并在确认策略挂载后才发送模型请求；旧版本未提供此能力时拒绝整理并提示升级，不退回可执行工具的总结。整理会调用当前已配置模型，生成结果仍需审阅和保存；模型 API 需要联网，不宣称离线总结。临时保护插件和工作进程会回收，独立原生记录仍由 Harness 管理。
- 显示 Harness 官方 ACP 返回的上下文占用、容量和百分比。该值随模型或压缩变化，只保存最新状态，不作为计费 Token、不加入累计或每日用量；未返回时不估算。
- 支持 ACP 回复及工具输出中的 PNG、JPEG、GIF、WebP 内联图片，刷新后可查看、下载，分叉复制独立记录；中断/失败时保留已收到的图片。工具和过程图片遵守各自显示筛选，回复图片正常显示；仅图片的回复也可成功结束。
- 图片按任务与本轮运行隔离，登录后才能访问。最多每轮 12 张、每张 2 MiB、边长 8192 像素、总像素 3200 万；无效/超限图片显示提示。不会抓取远程图片、渲染 SVG/HTML，图片二进制不写入文字记录或飞书卡片，不自动变成下一轮输入附件。
- 普通问题弹窗及计费 Token 统计仍受当前 Harness ACP 协议限制，未冒充原生支持。历史、配置和凭据保持兼容；新增数据库表保存上下文和输出图片。

验证：完整 Go 测试及 vet、37 项网页回归、115 个桌面/移动尺寸界面用例已通过。隔离官方 WSL Harness 回环测试覆盖上下文、总结工具拒绝及原会话恢复；合成回归覆盖图片协议、仅图片回复、任务工作流持久化、权限隔离、分叉、限额、筛选、取消保留及空闲 DOM 稳定。不调用真实模型或设备，未在日常账号执行完整安装/卸载测试。
