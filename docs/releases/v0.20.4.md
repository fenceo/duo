# Duo v0.20.4

## 安装器流程

- 首次干净安装不再显示“数据模式”选择页，直接选择数据目录；默认目录为 `%LOCALAPPDATA%\Duo\data`。
- 检测到已安装 Duo 时自动沿用原程序目录、数据目录和启动入口，进入短路径升级。
- 检测到旧便携版时显示来源路径；迁移页只确认启动任务和快捷方式接管，不复制、合并或删除旧程序、旧数据。
- 数据切换仍可在设置中进行，完整数据目录切换仅适合同一台电脑的恢复。

## 安全工作区迁移

- 脱敏工作区包现在包含任务、对话、执行记录、知识库、待办、备注、自定义工作模式和快捷指令。
- 自定义模式和快捷指令导入时追加保存，同名 ID 自动重命名并更新任务引用，不覆盖当前配置。
- 仍然排除密码、会话、飞书/API/AI/SSH/硬件凭据、机器路径和附件原文；附件需重新上传。

## 便携版与安装版

便携版无需安装，默认使用 `Duo.exe` 旁的 `data` 目录；安装版默认使用 `%LOCALAPPDATA%\Duo\data`。两者不要同时打开同一数据目录。跨安装方式或跨电脑搬运记录，请使用设置里的脱敏工作区导出/导入，不要直接复制正在使用的 SQLite 文件。
