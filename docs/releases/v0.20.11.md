# Duo v0.20.11

## 修复升级残留进程

- 修复 Windows 安装版自动升级时，Duo 服务已经退出但启动器未收到异步升级信号，导致托盘不可见、`Duo.exe` 残留并阻塞安装器的问题。
- 启动器现在同时检测待处理的升级暂存目录；即使服务最后一条信号丢失，也会安全退出并让安装器继续。
- 不改变任务、知识库、凭据或数据目录；升级仍然不会强制结束正在运行的任务。

## 发布文件

- `Duo-Setup-User-x64.exe`：Windows 安装版，支持新装和原位升级。
- `Duo-portable-windows-x64.zip`：Windows 便携版。
- 两个文件均提供 `.sha256` 校验文件。
