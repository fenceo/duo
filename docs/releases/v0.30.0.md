# v0.30.0

- Codex 账号卡片自动读取目标账号目录中的身份信息，显示邮箱/账号名称、套餐和账号 ID，同时保留用户自定义的备注名。打开列表不再只显示导入时填写的配置名称。
- 新增单个、全部及勾选账号刷新，通过目标环境的 Codex 原生账号接口更新身份和订阅额度。按服务返回的真实窗口显示剩余比例、重置时间与更新时间；查询失败保留同一身份的旧快照并明确标记，不显示成零额度。
- API / 中转站账号展示供应商和服务地址；不冒充支持订阅额度或 API 余额查询。令牌中包含订阅截止日期时显示为本地记录，不以令牌过期时间推算订阅。
- 新增套餐、账号状态、标签筛选，备注与标签编辑、邮箱/账号 ID 搜索和剩余额度排序。隐藏名称同时遮蔽邮箱、账号 ID、备注名和备注内容。
- Windows、WSL、SSH 使用各自的账号目录和 Codex 程序；原生刷新与登录/跨环境同步互斥，查询期间配置或账号改变时拒绝混用结果。移除引用同时清理展示缓存和备注标签，保留原生文件与已有任务。

在线刷新需要目标环境安装兼容的 Codex CLI，WSL/SSH 另需 Python 3。刷新只查询账号和额度，不创建模型对话；原生 Codex 可续期所选账号的令牌。当前仍未实现 Cockpit Tools 的 API 网关、多开实例与自动唤醒，本次覆盖 Codex 账号身份、额度和管理操作。
