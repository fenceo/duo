# Duo v0.24.2

- 修复旧任务升级后已有原生 Session、但没有账号绑定时无法原地续聊的问题。“切换 AI”新增明确确认原账号/API、保留原会话的选项；补齐绑定后可继续发送消息，不删除 Session、不重建历史。
- 确认前要求保持原引擎、执行环境、工作目录和权限；切换配置后清除勾选，打开或取消不修改任务。用户不能确认原账号时，仍可使用新会话接续历史。旧记录没有可靠账号归属，程序不会自动猜测。
- 修复 Windows Codex 桌面版更新删除旧版本 CLI 目录后，任务保存的旧路径无法启动的问题。仅对当前用户桌面版安装目录下已消失的版本路径寻找现有版本；现存固定路径、自定义路径和远端路径不变，不改写任务环境快照。
- 增加旧任务迁移、保留原权限、取消、重复提交、配置变化、事务回滚及 CLI 路径回归。测试使用合成数据，不发送真实模型请求。
