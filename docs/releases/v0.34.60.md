# v0.34.60

## 导航与便签

- 切换 AI、重建 AI 会话、绑定飞书私聊移回左侧任务行的“⋯”，操作固定到所点任务，防止异步切换误操作其他任务。硬件、桌面共享仍在任务工具栏。
- 便签直接替换左侧任务列表，不再弹窗。任务、归档、回收站、新建及选择任务可返回对应列表，保留便签自动保存与未完成草稿。

## 任务过程与分层知识

- 开启自动记录后，将每轮初级资料、来源和交接写入实际工作区 `.duo/tasks/<任务ID>/`，支持 Windows 和经 Python 3 访问的 WSL/SSH。既有资料可在本任务知识手动回填。
- 新会话按设置恢复本任务摘要、同工作区其他任务的有界交接和已确认平台共识。稳定来源 ID 去重，分叉引用原记录，连续原生会话不重复附带全历史。同步失败只报告提示，不改变模型轮次结果。
- 新增平台共识、系统知识、项目知识，显式从资料提升或手动编写；保存来源、适用条件、依据、验证状态和配置引用。相同来源、层级、范围重复提升不会叠加。
- 平台共识保存在 Duo 数据中，可镜像 `Duo/consensus/`；系统及项目知识镜像 `Duo/system/`、`Duo/projects/`。支持 Obsidian 编辑、冲突保护、跨电脑导入和数据备份。首次导入与外部正文修改回到待验证，不能靠修改 YAML 自动晋升。
- 常见凭据赋值禁止进入正式正文，密码仍应使用受保护配置。系统及项目知识先搜索、引用；技能/MCP 转化尚未实现。

## 保留与迁移

旧记录、候选结论、主题索引、Vault 路径及用户编辑保留，不自动批量搬迁或删除。工作区过程与 Obsidian 是两个目录，各自需要同步；Vault 不包含全部数据库、附件或 CLI 原生会话。具体开关、存储与接续规则见[分层知识与任务记忆](../knowledge-layers.md)。

本轮使用合成资料检查，不调用真实模型、真实硬件，不安装或重启现有 Duo。
