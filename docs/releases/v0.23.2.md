# v0.23.2

- 移除“轨迹”和独立“筛选”菜单，在“对话”旁直接勾选中间过程、命令与工具。默认显示中间过程，工具默认隐藏；已保存的显示偏好继续保留。用户要求、最终回复和错误始终显示。
- 打开任务先读取最近 5 轮，较早对话通过“展开更早对话”每次读取 5 轮，可重新收起。按完整轮次分页，初始要求和最终回复不会因执行记录较多而消失。
- 轮询从当前快照位置读取新增事件，不再从最早记录追赶，也不再携带全部历史轮次的结果。每轮较早执行记录分页读取，长工具输出展开时再读取全文。
- 聊天首屏不等待知识正文；聊天轮询只读取知识元数据，打开知识面板时再加载内容。
- 保持搜索定位、执行中补充、审批、排队与停止功能；历史页不改变实时游标，迟到的历史页不能回滚正在执行的状态或串入其他任务。

这些开关与折叠仅影响显示和按需读取，不删除数据库中的记录，不改变模型会话或知识沉淀。首次启动为分页读取创建索引。测试使用合成记录、临时目录及浏览器 fixture，不调用真实模型、不安装或重启现有服务；真实机器的升级与加载耗时仍取决于数据量、磁盘和执行环境。
