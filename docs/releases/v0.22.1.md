# Duo v0.22.1

- 右上角“任务知识”更名为“本任务知识”，说明它是全局知识库中的当前任务条目，保留编辑、纠错、验证和删除能力。“整理任务知识”改为可选的“手动整理”；任务面板与全局知识库增加互相跳转的入口。
- 新增“设置 → 知识库”，集中管理对话自动积累、所有任务共用的知识文件根目录和同步范围。全局知识库专注搜索与引用，可直接跳转到知识库设置。
- 知识库设置显示本机运行数据目录与实际 Markdown 文件目录，支持普通文件夹或 Obsidian Vault。知识、任务和对话继续使用原有数据库；Markdown 继续位于所选根目录下的 `Duo/`，完整数据迁移仍使用“数据与存储”。
- 更换知识文件根目录会在新目录同步当前范围，保留旧文件和本机任务知识；启用同步时，目录无效则保留原设置。设置读取失败、重复保存和过期响应不会覆盖当前编辑或触发额外同步。
- 清理便携使用说明与测试注释中的无关 AHA 文案。保留 `.aha2-context` 外来上下文检测及其回归测试：只检查文件名并提示，不读取或执行 AHA 内容；历史版本说明保留。

升级保留现有自动积累与 Vault 设置，不改变默认同步范围，不迁移数据库。使用与配置见[知识库说明](../knowledge-vault.md)。
