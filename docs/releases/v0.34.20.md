# Duo v0.34.20

- 修复 MiMo ACP 已完成却漏发正文时被误判为“未返回最终回复”：结束原生写入后核对 CLI 持久化结果，补回本轮最终回复。只匹配当前会话及当前输入，保留同一会话和历史，不重放对话作为新输入。
- 原生模型错误按认证、余额、限流或接口/模型兼容问题显示，不再全部显示为空回复；不回显可能包含请求头、Key 或用户输入的原始错误载荷。原生结果不可读取时保留流式回复并明确提示。
- MiMo API 配置范围与任务模型目录对齐，使用 `duo-mimo/` 路由，隐藏未配置账号的内置服务选项。刷新目录时排除专用 ASR/TTS 型号，它们不能使用代码会话的聊天/工具协议；其他自定义模型仍可手动配置。
- MiMo 模型写入思考和 `reasoning_content` 续接元数据，修正工具循环的配置。官方及 Token Plan 预设使用当前 CLI 对 MiMo 模型要求的 Chat Completions 协议；保存前提示套餐 Key/地址不匹配与不兼容的模型协议。
- 合并连续思考碎片和重复正文快照，补齐 MiMo 在工具更新中发送的参数，显示本轮所选模型及原生用量。原始事件保留供分页和搜索，不以模型自述判断实际模型。

升级后重新保存 MiMo API 配置以刷新原生模型元数据；Token Plan 选择套餐对应区域地址。旧任务闲置时可切换到相应 `duo-mimo/` 模型后继续，不需要删除任务或清空历史。配置和账号目录、权限、MCP 与其他原生偏好保留。

验收使用合成 HTTP/ACP fixture 和官方 MiMo 0.1.15 的隔离 HOME、假 Key、回环模拟接口；覆盖同一原生会话的模型切换、思考/工具续接、短回复及 HTTP 401。未读取真实 Key 或调用付费模型；模型目录认证成功不代表套餐内每个模型均已通过真实推理。

验证：Go 全量测试、vet、TypeScript 检查与构建、40 项网页回归、136 个桌面/窄屏界面用例通过；官方 CLI 回环原生测试通过。
