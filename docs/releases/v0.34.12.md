# v0.34.12

修复 DeepSeek Harness 已有任务的模型测试和飞书审批提醒。

- 已有 Harness 任务中的“测试列表模型”现在会发起测试，不再出现按钮可点击但没有响应的情况。沿用完整列表、账号/API 与额度确认、逐项结果和停止测试流程。
- 模型测试使用独立的只读原生会话，不发送原任务对话或附件，不更改原任务的模型、会话、权限和绑定；环境或 provider 身份变化后拒绝使用旧任务测试另一目标。
- Harness 官方工作区模式的原生审批现在会通知已绑定的飞书聊天，并提供当前任务网页入口。网页提交批准本次、拒绝本次或取消后，审批提醒关闭。
- 延续权限审批在 Duo 网页处理的方式：飞书提醒不发送工具命令全文、不提供直接批准控件，问题表单不能消费原生审批。归档、删除、取消及其他引擎的请求保持隔离。

回归覆盖模拟流式模型测试、任务会话不变、执行环境变化拒绝，以及模拟飞书投递、网页决定回传原生选项、旧卡片关闭和请求隔离。测试不调用付费模型，不向真实飞书聊天发送消息。此版本不增加 MCP 工具、普通问题弹窗、独立知识总结或计费统计能力。
