# v0.33.1

- 修正硬件连接阻塞升级：串口、TCP/SSH 控制台或继电器仅保持连接时允许准备更新，不再要求逐个手动断开。
- 正在发送的硬件数据、继电器操作，以及现有 AI 任务、终端会话等仍会阻止更新。检查与更新状态切换在同一锁内完成；进入更新准备后拒绝新连接、写入和电源动作。
- 下载或校验失败会解除更新状态，保留原硬件连接。只有实际退出重启时按正常关闭流程断开，更新后需重新连接；不会自动重放指令或切换继电器电源。
- 更新页明确说明连接会在重启时断开。无法从任意串口输出判断板端是否仍在烧录或运行，用户应先完成这类操作再更新。
- 继承 v0.33.0 的桌面预览人工控制修复。新增合成回归覆盖空闲连接、进行中的写入与继电器、更新期间请求和准备失败恢复；不连接真实硬件。
