# Duo v0.34.69

本版补齐任务原件、主题整理、笔记迁移与使用指引之间的流程。升级不会自动切换笔记路径、迁移用户文件或发起额外模型调用。

- **执行中维护任务状态**：正常公开进度可附带本轮有依据的目标、计划和里程碑增量，沿用逐字依据校验；随限频执行快照写入任务主 Markdown，结束时再合并最终增量。无有效更新则保留旧状态，人工维护区域仍受保护。失败、停止、分叉与工作区导出保留来源报告，不把工具活动当作成功。隐藏元数据不能充当公开完成证据，独立知识整理不会覆盖原聊天任务的目标与计划。
- **按主题合并已有知识**：含待修订的主题可显式使用所选任务的 AI 生成完整合并稿，发送原文与待修订，不续接原生聊天会话，不开放工具。生成结果保留为待采用稿，原正文和确认状态不自动改变；采用前检查正文与来源修订是否已变化。冲突保留为未决分歧，采用后仍需人工核对。
- **安全迁移笔记根目录**：在“知识库 → 目录与整理”预览新旧知识根、文件清单、重复、冲突和未同步修改；确认后复制并校验，全部完成才切换设置。保留知识身份、来源、修订与人工文件；旧目录不删除，目标异内容不覆盖，失败可重新预览后续传。
- **统一使用流程**：目录、逐轮记录、已有候选归档与迁移设置分组并列；整理按钮明确说明分类及任务范围，同步错误单独显示。待修订可直接查看与处理，内部任务状态元数据不显示为聊天正文。新增可照着执行的[使用与验收说明](https://github.com/fenceo/duo/blob/v0.34.69/docs/knowledge-acceptance.md)。

例行自动、一键、定时整理只处理已生成候选，不另起付费模型请求；“用 AI 整理本任务”和“用 AI 整理此主题”需要明确确认，会消耗所选模型额度。真实多引擎接续理解效果、图片历史恢复仍需用户实际验收。向量检索、无人值守付费整理、技能/MCP 转化不属于本版能力。
