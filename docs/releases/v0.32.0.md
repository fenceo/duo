# v0.32.0

- 设置中新增「用量统计」：查看全部任务或当前任务的累计、今日、最近 7 / 30 / 90 天用量。表格按日期和执行时所选模型汇总，列出执行次数、Prompt tokens、Completion tokens、Total tokens；同名模型跨引擎合并并标注引擎，不显示缓存命中率。
- 次数是 Duo 执行轮次，不冒充底层 API 请求数；一轮可包含多次模型请求。输入包含引擎回报的缓存用量，Total = Prompt + Completion。历史缺失用量与未记录模型名称明确标注，不以当前任务模型倒推历史。
- 统计读取完整已保存记录，包含归档和回收站任务，不受对话分页限制。每日按浏览器时区的开始日期归属，旧记录回退创建日期；跨日轮次归入开始当天，执行中数值为暂存值。不包含在 Duo 外执行的 CLI 用量，不作为账号账单。
- 排队消息可单独「撤销」，不影响当前执行及其他排队消息。已开始执行时拒绝撤销；重复请求幂等。保留撤销记录、原文和附件，空输入框自动放回草稿，已有草稿不覆盖，也可稍后点击「放回输入框」。
- 移除输入框下的工作模式管理齿轮；工作模式选择保留，低频管理移到「/ 指令 → 管理工作模式」。
- 串口连接后的「释放控制」移到默认折叠的「共享控制（高级）」，普通使用直接连接 / 断开。保留多任务控制权检查、取得控制和保持连接的交接能力。
- 新增合成回归覆盖单条撤销、运行中拒绝、原文附件保留、草稿隔离、用量合并、缺失数据、跨日与夏令时、鉴权和 CSRF；不连接真实模型或硬件。
