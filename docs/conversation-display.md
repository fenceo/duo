# 排队撤销与用量统计（v0.32.0）

排队记录下可点击「撤销」，只取消尚未开始的这一条。历史、原文和附件保留；输入框为空时自动还原，否则可稍后点「放回输入框」，不会覆盖正在编辑的草稿。若服务已开始执行，会明确拒绝撤销。停止按钮仍停止当前执行并取消全部排队消息。

「设置 → 用量统计」读取完整记录，支持全部任务 / 当前任务与 7、30、90 天日报。按日期和执行时的模型名称分组，同名模型跨引擎合计；次数按执行轮次，不等于底层 API 请求次数。输入含缓存，输出含引擎已计入的推理 Token；总量为输入加输出。引擎未提供的用量、历史未记录的模型名不估算，也不套用任务现在的模型。

日期以浏览器时区的轮次开始日计算，旧记录以创建日代替，跨日执行仍计入开始日。累计包含归档、回收站与执行中已有回报，不包含未执行的排队/撤销记录。统计页按打开、改变筛选或手动刷新读取，不增加对话轮询开销。

## 对话显示与历史加载

“对话”旁的两个复选框只控制显示，不修改记录、不改变 AI 执行和会话上下文。

- 中间过程：新浏览器默认开启，可关闭。主要显示中间回复及执行进度。
- 命令与工具：默认关闭，需要检查具体命令、工具结果时打开。长输出先显示摘要，展开单条记录后读取全文。
- 用户要求、最终回复、失败和停止错误始终保留可见。搜索命中会临时展开目标记录，但不会改写复选框偏好。
- 设置保存在当前浏览器；升级保留已保存的旧显示偏好。“轨迹”和独立“筛选”菜单已移除。

打开任务先读取最近 5 轮和仍在执行/排队的轮次，顶部“展开更早对话”每次加载 5 轮，按时间排列。可“收起早期对话”回到最近内容，不删除历史。特别长的一轮先读取最近 100 条执行记录，较早记录继续按页加载；最初要求和最终回复固定保留。所有记录仍可通过搜索定位。

后台从快照的最新事件位置读取增量，不把未展开的历史自动重新下载。旧页与实时消息使用各自的游标，查看历史不会打断新消息；加载失败可重试，切换任务后丢弃迟到的响应。较早历史页不会覆盖较新的轮次状态。

知识正文不阻塞对话首屏。聊天页只获取用于“已自动记录”等提示的元数据，打开知识面板时再读取正文。原有知识文件、导出、摘要和模型上下文均不受对话折叠影响。

合成回归覆盖长对话、无丢失分页、同一时间创建的轮次、任务隔离、搜索、隐藏标签、知识延迟及工具全文按需读取。实际升级速度还受数据库索引初始化、磁盘和服务环境影响，不能由合成测试等同推断。
