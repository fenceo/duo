# 跨引擎任务接续

Duo 将“任务记录”与“原生引擎会话”分开处理。Codex、Claude Code 和 DeepSeek Harness 的 session ID 不能互相复用；切换工具时会创建新的目标任务，原任务保持不变。

## 用户流程

1. 在任务菜单或任务标题栏选择“切换继续”。
2. Duo 只在本机生成脱敏预览，不调用模型。
3. 选择目标环境、工具、模型和工作目录，检查预览后确认。
4. 确认后才把历史快照发送给目标引擎，并创建新的原生会话。

默认快照包含已保存的知识和最近已完成的对话轮次，排除工具事件、运行日志、附件、原生 session、环境凭据和绝对工作目录。内容经过路径、私钥、API key、密码、Bearer 和常见令牌脱敏，并有总长度限制。

接口为：

- `GET /api/tasks/{id}/continuation/preview`：只读生成本地预览。
- `POST /api/tasks/{id}/handoff`：要求 `confirm: true`，创建目标任务并提交第一轮上下文。

转接关系只保存源/目标任务 ID、引擎和统计信息，不保存凭据或原生会话。目标任务的第一轮会明确标注“历史仅供参考”，要求目标引擎先检查当前工作区。
