# 跨引擎任务接续

Duo 将任务记录与原生引擎会话分开。v0.24.1 起，“切换 AI”保留同一个任务 ID、聊天记录、知识、待办和未发送草稿，修改下一轮执行的引擎、模型、权限和执行位置。Codex、Claude Code 和 DeepSeek Harness 的原生 session ID 不能互相复用。

## 用户流程

1. 等当前运行结束，或先停止并取消排队。点击标题栏或任务菜单的“切换 AI”。
2. 选择引擎、模型和权限。模型列表读取目标环境的原生配置，不发测试提示词；也可填写模型 ID，列表存在不等于调用可用。
3. 默认沿用工作目录，默认选择“完整历史文本 + 接续摘要”。展开执行位置可更换环境和目录；也可明确选择仅笔记与共识。阅读摘要，必要时打开完整脱敏文本。
4. 确认切换只保存配置，不立即调用模型。回到原任务发送下一条要求后才开始执行。
5. 同一引擎、环境和目录只换模型时继续原生会话；换引擎或执行位置时建立新会话。Harness 权限改变也需新会话。账号管理中的登录切换不执行此接续流程。

“会话信息”和“复制链接”从顶部移到左侧任务的操作菜单，外部项目指令及会话恢复诊断仍可查看。

## 账号独立管理

v0.31.1 起，账号不绑定任务。在「账号管理」中添加或导入，再选择「切换到环境」，直接修改 Windows / WSL / SSH 的原生登录和服务配置。切换账号不触发新会话或历史接续，也不修改排队消息。详见 [环境账号管理](environment-accounts.md)。

## 历史如何交接

- 内联摘要最多约 13,000 字符，优先最近共识、前提、未解决事项、笔记和最后几轮。它不声称覆盖全部历史，也不是额外模型总结。
- 完整所选文本包含本任务全部已结束的聊天轮次（包括失败、停止）、追加引导、已有工具记录、任务笔记及结构化记忆。连续累积的流式文本合并为最终片段，不重复附加相同正文。每轮保留原引擎标记。
- 完整文本作为可读取的 Markdown 文件传入执行环境；较早内容由目标引擎按需读取。不是把全部文本一次性灌入模型上下文，也不能保证模型已经读取每一条。每轮重建临时文件并在结束后清理，提示词提供当轮有效路径；不会往用户项目写历史文件。
- 原生 session、凭据文件、图片等二进制附件不转移；需要原图时重新附加。历史工具日志是资料，不是待执行命令。内容做路径和常见凭据脱敏，但不能保证任意正文里都没有敏感信息，提交前仍可查看全文。
- 单次所选历史上限 64 MiB，超过时明确拒绝，不静默裁掉早期记录。历史资料只在预览或切换引擎/执行位置时构建，不加入聊天轮询负载。数据库中的原始记录不删除。
- “新建会话”明确清除接续文件绑定，之后只按自动恢复知识设置补回少量资料；它与“切换 AI”用途不同。

## 一致性与接口

每个已提交轮次保留引擎、模型和接续历史。账号独立由目标 CLI 原生登录管理，账号切换不修改这些快照。跨引擎或执行位置的切换在同一事务中保存配置、历史和旧会话信息；重复提交可重试，过期预览拒绝提交。

接口为：

- `GET /api/tasks/{id}/continuation/preview?mode=full`：本地摘要、全文字节数和指纹，不调用模型。
- `GET /api/tasks/{id}/continuation/archive?mode=full`：需要登录的纯文本全文预览。
- 新版“仅任务笔记与共识”使用 `mode=notes`，保留尚未独立验证的笔记并明确标注。兼容范围 `summary` 仍只包含标为已验证的笔记，`recent` 仍使用已验证笔记和最近 8 轮成功对话。
- `POST /api/tasks/{id}/handoff`：要求 `confirm`、预览指纹、任务绑定版本、明确的目标配置和权限；原子更新原任务，不提交模型轮次。旧版没有指纹的转接请求会被拒绝。旧任务明确确认原配置时可传 `preserve_legacy_session=true` 与匹配的 `expected_legacy_session`；`mode_id=__current__` 保留原权限快照（含早期未显式保存的默认权限）。引擎、执行环境、目录、权限发生改变时拒绝保留旧会话。
- 模型目录支持明确 `profile_id`，或者用 `task_id` 读取任务绑定；任务内模型测试还核对绑定版本，仍需要用户单独确认付费测试。

回归使用合成记录、临时配置目录和 fake runner，覆盖同任务跨引擎、换模型、原生登录切换不改任务/会话、长历史、重复与过期提交、事务回滚、排队隔离、原生模型目录、草稿和窄屏。真实模型接续质量、具体 provider 兼容性和 WSL/SSH 远端读档效果需另行授权实测；没有发送真实模型请求。
