# 桌面共享控制

工作台“桌面共享”入口选择整个桌面或一个窗口，并明确开启共享。它是和硬件调试并列的 MCP 工具能力，共用任务工具传输层，桌面授权状态独立管理。共享时入口显示“桌面接管”。默认仅查看，勾选后才允许 AI 使用键盘和鼠标。共享的是运行 Duo 的 Windows x64 电脑，窗口必须保持前台；截图来自可见区域，遮挡窗口也可能进入画面。

开始共享后，在 Codex 或 Claude Code 任务中使用允许工具的工作模式发送下一条消息。Duo 通过任务 MCP 接入 `desktop_observe` 和 `desktop_action`，支持截图、点击、双击、右键、滚动、文字和按键组合。只读规划模式不接入此控制工具。WSL/SSH 引擎需要能访问 Duo 的任务工具地址，沿用硬件工具的地址设置。

v0.33.0 起，网页预览可人工控制。开始共享后点击「我来操作」，再在预览上单击、右键或滚动；切换为「双击」后单击一次即可发送双击。画面获得焦点时可输入普通字符和按键组合，中文等文字可使用「发送文字」。Escape、结束手动控制、关闭面板或隐藏网页会释放人工控制。人工控制独立于「允许 AI 操作」开关，不会把 AI 的只读权限升级。

人工控制期间 AI 的桌面观察和动作暂停，结束后需重新观察。浏览器控制令牌不进入模型工具 schema；它只允许当前共享目标，仍核对前台窗口、区域、截图有效期和动作边界。人工输入不会被误认为 AI 抢占用户鼠标。连续刷新保留最多 8 份近期画面元数据，避免刷新刚好让用户正在点击的画面失效；任何动作都会使所有旧画面失效，失败不会自动重试。手动模式约 1.2 秒读取一次画面，忙时不累积轮询；控制页断开、无成功刷新 60 秒后释放人工控制，共享总授权仍为 30 分钟。

共享为同一时刻单个任务的临时授权，30 分钟到期，重启服务后关闭。停止共享立即撤销后续访问；不会停止已经发送到 Windows 的那一次短输入。可从任意任务打开面板点击“停止共享 / 接管”。关闭面板不等于停止共享。

每次动作要求一张 30 秒内的新截图，一张截图只允许一次动作。前台窗口或共享区域发生变化时拒绝旧动作；AI 操作还会检查物理用户输入变化。截图和输入内容不写进 Duo 的工具日志，日志只保留工具名称和执行结果；画面作为模型工具结果送入当前引擎，原生引擎的记录策略由该引擎管理。

这是实际桌面的协作控制，不是虚拟机或后台隔离。管理员窗口、安全桌面、锁屏以及部分受保护内容可能无法观察或控制；程序不会绕过 Windows 权限边界。输入抢占检测尽量让用户优先，不保证对所有并发物理输入和应用动画进行完全隔离。

实现独立使用 Windows GDI / SendInput，没有复制 AHA2 的源码，也不是完整移植。对照 [AHA2 共享控制契约](https://github.com/ChinaKai/AHA2/blob/main/docs/shared-control-contract.md) 与 [画面传输契约](https://github.com/ChinaKai/AHA2/blob/main/docs/desktop-stream-contract.md)，Duo 尚无其联合协同、拖拽、目标窗口前台恢复、隔离桌面、自适应 JPEG/WebSocket 视频链路。本版保留“目标窗口必须前台”的限制；约每秒刷新的 PNG 预览不宣称是低延迟远程桌面。

回归使用虚拟画面和独立 CI 窗口，不对用户正在使用的桌面自动点击或调用真实模型。
