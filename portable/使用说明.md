# Duo便携版 · Windows x64

如果希望使用开始菜单、桌面快捷方式或更简单的升级和卸载流程，请从 Releases 下载 `Duo-Setup-User-x64.exe`。安装只作用于当前 Windows 用户，不需要管理员权限。本说明对应便携 ZIP，两种方式使用相同的程序和数据格式。

## 开始使用

1. 把整个 ZIP 解压到一个有写入权限的固定目录，例如 `D:\Apps\Duo`。不要在压缩包里直接运行。旧版简作首次转入 Duo 请使用安装 EXE，不要用这个 ZIP 覆盖旧安装。
2. 双击 **Duo.exe**。首次自动检测 Windows / WSL 中的 Codex、Claude 及本地登录配置。选择执行环境、工作目录并设置工作台密码即可；Windows 可点“选择文件夹”。SSH 与自定义程序位置在“高级设置”中填写。检测可能启动 WSL，不会调用模型。请从资源管理器、开始菜单或普通快捷方式启动；从 Codex 或其他受限沙箱进程启动时，Windows 可能阻止访问 WSL 服务和计划任务。
3. 配置完成后会打开浏览器；右下角系统托盘里可以打开工作台、查看数据目录、重启或退出服务。
4. 如需自动运行，勾选托盘菜单里的“登录 Windows 后自动启动”。只设置当前用户的“Jianzuo User”计划任务，不需要安装系统服务。

适用于 Windows 10/11 x64，启动器使用系统 .NET Framework 4.8。服务已编译，运行Duo不需要另装 Go、Node.js 或 Python。执行任务的环境仍须安装并配置 Codex 或 Claude Code；WSL、SSH、Tailscale 按需配置，不包含在本包里。

## 手机和其他电脑访问

首次配置勾选“允许局域网和 Tailscale 访问”，服务会监听这台电脑的网络接口。然后在“设置 → 访问地址”检查并保存局域网、Tailscale 地址。设置中这些 URL 是入口地址；改变监听接口或端口需退出后修改 `data/config.json` 的 `listen`，再启动。

同局域网访问 `http://电脑局域网IP:端口/`；异地通过同一 Tailscale 网络访问 `http://电脑TailscaleIP:端口/`。仍需输入工作台密码。Windows 防火墙需要允许所选端口，Tailscale 的访问规则也需允许连接。程序不会自动关闭防火墙。

飞书新生成的任务清单、任务详情卡片会带已配置的入口链接；任务详情链接定位到对应任务。机器人扫码配置在“设置 → 飞书连接”。同一个机器人只应连接一个Duo实例。

在飞书选中任务后直接发送要求，每轮执行使用一张卡片显示排队、执行进展、最近回复和最终结果；已在飞书选中的任务从网页开始执行时也会同步。卡片按执行记录和完整回复段落更新，不保证逐字显示。没有新内容时不会反复刷新，也不再额外发送“已收到”或重复的完成消息。

切换到其他任务后，已开始的那一轮仍在原卡片更新；后续绑定不会补发旧任务。长结果在卡片中截取，完整内容在网页保存。小号“局域网 / 远程”按钮可打开对应任务，远程使用设置中的 Tailscale 地址。停止、执行失败或服务中断会显示在卡片。

“整理知识”生成草稿，查看内容后可直接点击飞书卡片里的“保存知识”。网页任务知识面板也提供草稿预览、“编辑草稿”和“保存草稿”；知识卡片的打开链接直接定位到此面板。若知识在生成期间被修改，请在网页手工合并，旧草稿不会覆盖新版本。再次点击“我的任务”可取得精简后的任务清单，历史卡片不会批量重发。

网络错误会自动重试。连续失败后停止刷新卡片，任务结束时改用文字通知；若飞书消息接口整体不可用，文字也可能发送失败，但不会影响任务执行或网页结果。

## 任务、搜索和文件

左侧按执行环境和工作目录收纳任务，点目录可折叠。任务页右上角“⋯”可置顶、归档、改名、连接飞书或恢复任务。归档保留对话、知识和便签，恢复后可继续执行；正在运行的任务不能归档。归档不会自动断开硬件连接，使用完设备请先手动断开。网页与飞书默认任务列表均隐藏归档任务。

左侧搜索同时查任务标题、对话、知识和便签，包含归档任务。点击结果可打开对应任务或知识/便签；对话结果定位到附近记录，可点击“从开头查看”。

任务里的“文件与改动”读取该任务的 Windows、WSL 或 SSH 工作目录：可逐层浏览、筛选当前列表、预览 UTF-8 文本、下载单个文件，以及查看当前 Git 改动。Git 差异区分暂存和未暂存，包含之前已有修改，不代表本轮 AI 工具的改动。目录本身不是 Git 仓库时仍可浏览文件。

文件面板只读取，不提供编辑、删除、提交或回退。单目录最多展示 500 项，文本预览前 128 KiB，单文件下载上限 32 MiB；二进制或非 UTF-8 文件请下载查看。符号链接、特殊文件、Git 内部目录和越界路径不会打开。SSH/WSL 读取依赖对应环境的 Python 3，查看差异还需 Git。

## 任务交互终端

打开任务的“终端”，点击“打开终端”，即进入任务保存的 Windows、WSL 或 SSH 环境和工作目录。支持中文、颜色、Tab、方向键、Ctrl+C，以及分屏/全屏自动缩放。选中终端文字后可“带入对话”，检查后再发送给 AI 工具。

同一页面切换任务会保留终端，同时最多 8 个连接；刷新、关闭页面或退出登录会结束终端，网络中断最多约 65 秒后清理。终端中的普通子进程随连接结束，手动脱离终端的后台进程不保证退出。终端输出只保留在当前页面，不自动保存为任务记录。PowerShell 命令历史仅在会话内保留，Linux 按对应 Shell 的历史设置处理。

终端需要 Windows 10 1809+。SSH 保持严格主机指纹检查，须先在服务用户下确认远端指纹；可以使用已配置的密钥，或在终端提示时输入密码。已有活动终端的任务需先结束终端再归档。硬件调试有独立的交互终端，可直接操作串口上的 Linux / U-Boot。

## 数据、升级和迁移

便携版的 `data` 在 Duo.exe 旁边，首次启动才生成；新安装版默认使用 `%LOCALAPPDATA%\Duo\data`，已有安装继续使用原目录。数据库 `jianzuo.db`、`Jianzuo User` 启动任务和安装标记保留为兼容身份，不因改名重建。数据目录保存配置、任务、知识、便签和硬件配置；配置飞书后含机器人凭据，请勿把整个目录当分发包分享。

升级：在“设置 → 版本更新”检查新版。0.19 起明确显示安装方式：安装版下载完整 EXE 并运行安装维护流程；便携版校验 ZIP 后备份、替换运行文件。任务、终端或硬件连接未结束时拒绝更新，请先安全结束工作。准备更新期间阻止新工作进入，重启后网页核对目标版本再刷新；超时不冒称成功。安装版手动升级使用同一个安装 EXE，不要改用 ZIP 覆盖。日志位于数据目录的 `update.log`，安装失败另查看安装日志；重要数据应退出后完整备份，程序回退不代表数据库可以降级。不要在运行中复制单个 `jianzuo.db`，可能遗漏 SQLite WAL 中的内容。

从便携版迁移到安装版：先退出便携版，运行安装器，核对显示的原程序及数据路径。若需接管可识别的旧自启动任务，必须在迁移页面明确确认；未知归属入口不会被覆盖。原 `data` 保留在原位置，不重置数据库和密码，也不自动删除旧便携文件。因此以后不要连同旧目录一起删除正在沿用的 `data`。从安装版迁移到便携版时，先卸载程序并保留数据，再把原数据目录指定给便携版；不要复制正在使用的数据库目录。

换电脑：退出服务后复制整个便携目录，并重新检查工作目录、执行环境和访问地址。Codex / Claude 登录、原生会话、源代码、WSL 发行版、SSH 密钥仍在各自环境中，Duo `data` 不包括它们。新电脑可新建任务；要续接旧工具会话，需要原来的环境和会话仍可访问。

卸载：安装版使用开始菜单里的“卸载 Duo”，会删除程序、快捷方式和“Jianzuo User”任务，但保留数据目录。便携版取消托盘里的自启，退出后自行删除程序目录；两种方式卸载前都建议先备份数据。

## 常见问题

- 双击没有新窗口：查看系统托盘；再次双击会打开已有实例的网页。
- 提示端口占用：程序不会结束其他服务。首次配置可换端口；已有配置可在退出后修改 `data/config.json` 的 `listen` 及访问地址。
- 提示数据目录正在使用：先退出使用同一 `data` 的另一份Duo。
- 浏览器关闭后 AI 任务继续运行，但交互终端会结束；要停止后台服务，应通过托盘退出。
- 托盘被异常关闭时，服务通过控制管道结束；异常中断的任务需检查后手动继续。
- 运行日志位于 `data/service.log`。
- WSL 检测失败或看不到发行版：先用普通 Windows 用户打开 PowerShell 执行 `wsl.exe --list --quiet`。若从 Codex/受限沙箱启动失败，请改从资源管理器或开始菜单启动Duo；发行版、用户、代理、Git 和 SSH 配置分别按所选 Linux 用户检查。

命令行高级用法：`Duo.exe --data "D:\DuoData"` 指定独立数据目录；`--background` 只显示托盘、不自动打开浏览器。

本包不携带任何现有账号、机器人凭据或任务数据；不是 AHA/AHA2 安装包。


## AI 工具、推理强度与 SSH 发现（0.6.0）

新建任务可选 Codex 或 Claude Code，模型列表随工具切换，并保存推理强度。默认不覆盖工具原来的强度设置；Codex 的可选强度优先来自该环境模型缓存。Claude 提供常用别名和自定义模型，是否可用由该环境账号/网关决定。现有任务继续使用 Codex，不会切换会话。新任务的工具、模型、强度及执行环境固定保存，继续对话和整理知识均沿用它们。

设置里可分别配置两个 CLI 的路径、默认模型及默认工具；飞书新建任务使用默认环境的默认工具，进入已有任务则保持原工具。Claude 使用 print + stream-json 和精确 session ID 续接，保留原生配置，不添加自定义系统提示词或强制子代理。采用 acceptEdits 文件编辑权限；需要另行授权的工具会显示失败说明，可在该环境的 Claude 中配置权限后继续。检查 Claude 仅检查本地认证配置，不代表服务端密钥或模型验证通过。

“设置 → 执行环境”和“硬件调试 → 添加连接”均有“发现局域网 SSH”。从运行Duo的电脑扫描直接连接的 IPv4 私有局域网；一次最多 /24、4 个端口，默认 22 和 2222。读取 SSH 服务标识，不登录、不尝试密码、不运行远程命令。选中已确认的 SSH 服务可填入地址和端口，再补全用户、工作目录及认证设置。可以停止扫描，关闭窗口或退出登录也会取消；每次最长 45 秒。不支持自动发现 Tailscale 或跨路由子网，可手工填写这些地址。

## 串口交互终端（0.7.0）

在任务的“硬件调试”中点击“＋”，选择串口和波特率，然后“保存并连接”。端口列表显示 COM 号和设备名称，常用设置为 115200、8N1；高级参数可以调整数据位、校验、停止位和 DTR/RTS。新连接默认不拉高 DTR/RTS，旧配置保持原行为。

连接后点击黑色终端即可输入，支持 Enter、Tab 补全、方向键历史、Ctrl+C、ANSI 颜色和连续 UTF-8 中文输出。补全、历史和命令本身由板上的 Linux / U-Boot 提供。手机可点终端下方的快捷键。默认回车 CR、退格 DEL；兼容设置和本地回显位于“文本 / HEX 发送与终端选项”，也可在这里按字节发送。

暂停显示会同时暂停输入，后台仍接收；清屏仅清当前显示。支持选中文字带入对话分析、连续文本日志导出和文本/HEX 收发日志。后台每个连接最多保留最近 2000 条记录，首次打开显示最新 250 条。关闭面板或浏览器不会断开设备，需要释放串口时请点“断开”。重连和切换任务会丢弃尚未发送的键盘输入，历史显示不会自动发送终端查询响应。

USB 串口需要插在运行Duo服务的电脑上，其他局域网或 Tailscale 设备通过网页操作该串口。选择正确 COM 号、波特率后手动连接，不会自动登录、发送复位命令或修改板上 stty；串口本身不提供窗口尺寸协商。

## 共享设备、多终端与板子电源（0.8.0）

硬件面板的“＋”新增一个全局设备并关联当前任务；“设备库”将已有设备添加到其他任务。配置修改会影响所有引用它的任务，需先断开设备。“移出当前任务”只解除关联，保留设备库和记录。旧设备自动迁移为共享设备，并保留原任务关联。

已连接设备显示控制任务；其他任务可查看收发，但发送须“取得控制”。接管会更新控制凭据，旧任务尚未发送的输入会被拒绝。“释放控制”保留连接；“断开”释放串口。日志保存控制任务标识，可勾选“日志仅显示本任务记录”后导出或带入对话。

终端默认跟随任务的环境和工作目录。“＋”可在同一任务中另开 Windows / WSL / SSH 环境及目录，通过下拉列表切换。各会话独立，不改变 AI 的环境或路径。结束单个终端不影响其他终端；刷新/关闭网页仍会结束该页面的所有终端。

新增设备时选择“串口继电器 · 板子电源”，填写实际 COM 口（可更改）、继电器地址及 COM+NO/COM+NC 接线。支持用户说明中的 CH340 A0 协议，默认 9600、8N1、地址 1。接线未选择不能保存，程序不会猜测。连接本身不发送继电器命令，点击查询获取反馈；上电、断电、断电重启均显示目标确认。

控制按钮发送带反馈指令，不发送换行；4 字节为 A0、地址、操作码、前三字节和的低 8 位。继电器反馈反映触点状态，不检测板子电压或是否启动。未收到有效反馈会显示未确认且不自动重试。断电重启必须先确认断电反馈，等待 1–60 秒（默认 3 秒），再请求上电；中途断线或取消可能停在断电状态，应重新查询后人工处理。操作期间拒绝重复电源操作、接管和断开。

继电器是应用内的设备能力，协议不交给 AI 临时拼接。0.9 起可授权任务中的 AI 调用这些设备。

## 让 Codex / Claude 使用硬件（0.9.0）

0.9.1 起，硬件面板顶部显示“本任务 AI 硬件”：每台设备的连接状态、读取/发送/电源权限，点击设备可直接设置。无需提前连接，AI 会按任务需要调用连接工具。设备库显示所有关联任务、各自权限和当前控制任务，点击任务名称可切到该任务的硬件面板。“已添加”不等于已授权，“已授权”也不等于当前已连接。任务执行中还会显示“本轮”权限；运行中新增权限仍从下一轮生效。

0.9.3 起，对话顶部可选择“只看结果”或“全部”，也能分别勾选“命令与工具”和“中间过程”。默认只显示你的消息、已完成任务的最终回复及执行失败/停止信息；运行状态和停止按钮保持可用。筛选只改变网页显示，原始记录完整保留，飞书消息不受影响。偏好保存在当前浏览器，适用于所有任务；其他电脑、手机或不同访问地址可分别选择。搜索命中被隐藏的消息时会临时显示该条，不修改偏好。

1. 在任务的“硬件调试”中，通过“＋”或“设备库”加入设备。
2. 选择设备，点“AI 使用”。按需勾选“连接、读取日志和查询状态”，控制台可另外允许发送命令，继电器可另外允许上下电。
3. 保存后发送下一条任务要求，例如“读取最近的串口日志，并查询继电器状态”。网页和飞书使用相同权限。

每个任务、每台设备分别授权，默认关闭。开启电源权限后，AI 可直接上电、断电或断电重启，不再弹出网页确认。发送权限可在板子上执行命令；读取的日志会进入所选模型的上下文。AI 复用Duo连接，不会自行抢占其他任务的控制权。

硬件连接属于运行Duo的电脑，与 AI 执行环境无关。Windows 任务自动使用本机服务；0.9.2 起 WSL 优先尝试 127.0.0.1，再尝试设置中的局域网、Tailscale 地址，并在实际环境中验证服务。SSH 优先使用 Tailscale 地址。所选环境需要自己的 Codex / Claude 安装及有效账号；WSL/SSH 还需要 Python 3。Duo不会替你迁移或修复模型账号。

新增授权从下一轮生效；减少授权会立即撤销本轮硬件凭据，下轮重新按最新权限接入。停止任务也会撤销工具权限，但不会自动断开共享设备，已经发出的指令不能撤回。断电重启中途停止可能停在断电状态，请重新查询并处理。

工具操作记录在任务和硬件日志中。不需要额外安装技能，也不修改全局 MCP 配置；调试流程复杂后可再编写技能组合这些工具。此权限只控制Duo提供的硬件工具，不能限制 CLI 原有的系统访问权限。

## 0.10 工作台外观与执行记录

默认浅色，左下角“外观”切换深色。上方“对话”折叠每轮命令和中间过程，点击该轮“执行记录”可单独展开；“轨迹”展开全部记录，“筛选”可单独选择命令与工具、中间过程。最终回复与错误始终显示，原始数据不会删除。记录中的耗时是本轮创建至完成的总时长，包含排队。搜索会自动展开命中的记录。

右上角“文件 / 终端 / 硬件”打开工具侧栏，“更多”中是任务知识和便签。手机窄屏点击“对话”或关闭侧栏可返回聊天。工具与任务、设备授权关系保持不变。

设置里的“检测环境”也可供已有用户使用：只读检测本机，结果不自动保存、不覆盖旧配置；添加后选好工作目录，点击“保存设置”。已有登录配置不代表模型额度、网关或网络一定可用，需以实际执行为准。

## 0.11 工作区、模式、附件与彩色便签

左侧“选择工作区”弹出服务电脑的目录选择器，切换 Windows / WSL / SSH，逐层浏览或输入绝对路径。选中后可保存为常用工作区并创建任务；新建任务也有“浏览文件夹”。WSL / SSH 目录读取需要该环境中的 Python 3。

输入框中的模式可随每轮切换：“直接执行”沿用当前文件修改权限；“分析规划”使用 Codex read-only / Claude plan，不注入Duo硬件工具。齿轮可增加自己的模式名称、执行方式和要求。内置模式不加额外提示词；自定义要求只在选择该模式时加入。模式不是隔离另一台机器，也不改变任务所属环境、模型和工作目录。

“/ 指令”可保存并填入常用要求，检查后点“开始”。“附件”支持选择文件、拖放文件和粘贴图片，每条最多 5 个、每个 8 MiB。附件保存到Duo数据，并传入本轮 Windows / WSL / SSH 执行环境；图片通过所选工具的图片输入交付，其他文件提供可读取的路径，是否能解析取决于所选工具及环境。上传本身不调用模型，点“开始”才发送给所选 AI。附件草稿只保留在当前页面，提交后可在对应对话下载。

新任务可以先不填要求。输入内容或添加附件后点“开始”；执行中可“追加”到队列，或“停止”取消本轮和排队消息。后续消息自然沿用原生会话，不再需要单独的“继续”按钮。

右上角 ⋯ 可重命名、置顶、归档、删除会话，也可双击标题重命名。删除进入回收站并解除飞书绑定，恢复后在“已归档”中。删除、归档不清除工作目录文件；删除时需先结束活动任务、终端及该任务控制的硬件。回收站没有永久清空功能。

回复底部显示本轮引擎实际返回的 token 用量、执行耗时和完成时间。新记录耗时从实际开始计算；旧记录从创建时间计算，可能含排队。旧记录或失败轮次未返回用量时显示“未提供”，不做估算。Codex 缓存读取包含在输入 token 中；Claude 缓存 token 分开返回，合计时加入一次。

彩色便签常驻左下角，可切换“全部 / 本任务”，支持黄、绿、蓝、粉、紫五种颜色。便签仍按任务保存；跨任务查看时显示来源，点 ↗ 将内容放进当前对话，点正文编辑。

左下角“外观”可调整主题、强调色、对话字号、侧栏及正文宽度、紧凑布局、便签与路径显隐，实时预览，保存到当前浏览器。不同浏览器或访问地址可分别设置。

## GitHub 版本更新（0.12）

在“设置 → 版本更新”查看当前版本和安装方式，点击“检查更新”读取 GitHub 最新正式 Release。检查结果提供更新说明、自动更新按钮，以及对应安装方式的 EXE 或 ZIP 下载入口。预发布版和草稿不会作为正式更新。

检查在运行Duo的电脑上执行，需要这台电脑能连接 GitHub。默认不发送任何任务、工作目录或账号凭据。确认更新且服务空闲后才进入维护；其他平台继续提供手动下载。网络失败、访问限流、没有正式版本会分别提示。

需要使用自己的发行仓库时，展开“更新来源”，填写 GitHub 的 `用户名/仓库名` 或仓库主页 URL，再点“保存来源”。仅支持公开仓库；留空恢复官方仓库。自动安装只接受该仓库正式 Release 中固定名称的对应类型发布包，并验证其 SHA-256；`data` 不会被覆盖或上传。更换来源意味着信任该仓库的可执行代码，请仅使用可信维护者的发行版。
